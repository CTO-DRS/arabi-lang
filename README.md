# عربي — لغة برمجة عربية بالكامل

<p align="center">
  <img src="https://img.shields.io/badge/الإصدار-1.3.0-blue" alt="الإصدار">
  <img src="https://img.shields.io/badge/الترخيص-MIT-green" alt="الترخيص">
  <img src="https://img.shields.io/badge/Python-3.8%2B-orange" alt="Python">
</p>

**عربي** لغة برمجة كاملة صُممت لتكتب بها الكود بالعربية من أوله لآخره: متغيرات، شروط، بدّل/حالة، حلقات، دوال، قوائم، قواميس، معالجة أخطاء، برمجة كائنية، ووحدات قابلة للاستيراد — كل ذلك بكلمات مفتاحية عربية ورسائل خطأ عربية واضحة تخبرك بالضبط أين المشكلة وما الحل.

بنيت اللغة بلغة بايثون (بدون أي مكتبات خارجية) كمفسر ينفذ الكود سطرًا بسطر، بطريقة مشابهة لفلسفة بايثون نفسها: بسيطة، مقروءة، والكتل تُحدد بالمسافات البادئة.

```text
دالة مضروب(ن):
    لو ن <= ١:
        أعد ١
    أعد ن * مضروب(ن - ١)

اطبع("مضروب ٦ =", مضروب(٦))
```

---

## المميزات

- **صياغة عربية بالكامل**: `لو`، `وإلا إذا`، `وإلا`، `بدّل`، `طالما`، `لكل`، `دالة`، `أعد`، `صح/خطأ`…
- **أرقام بالصيغتين**: استخدم `٤٢` أو `42` كما تشاء، والفاصلة `،` أو `,`
- **كتل بمسافات بادئة** مثل بايثون — لا أقواس معقوصة تشوش الكود
- **دوال كاملة**: معاملات، إرجاع قيم، تعاود، وإغلاق (Closures)
- **قيم افتراضية ومعاملات بالاسم (جديدة في 1.2)**: `دالة فاتورة(الصنف، سعر = ١٠)` واستدعاء بـ`فاتورة("قلم"، سعر = ٢٠)`
- **دوال سهمية (جديدة في 1.2)**: `ضاعف = دالة(س) => س * ٢` — دالة على سطر واحد تُمرر كقيمة
- **وحدات من ملفاتك (جديدة في 1.2)**: `استورد هندسة` أو `من هندسة استورد مساحة` — انظم مشروعك في ملفات `.عربي`
- **بدّل/حالة/افتراض (جديد في 1.3)**: تفرع أنظف من سلسلة `لو` الطويلة عند مقارنة قيمة واحدة
- **خريطة/مرشّح/اختزل (جديدة في 1.3)**: دوال ترتيب أعلى جاهزة تعمل مع السهميات
- **ملفات وجيسون (جديدة في 1.3)**: وحدة `ملفات` للكتابة والقراءة، ووحدة `جيسون` للحفظ والتبادل
- **برمجة كائنية**: `صنف`، `هذا`، الوراثة بـ`من`، واستدعاء الأب بـ`الأصل`
- **هياكل بيانات جاهزة**: قوائم وقواميس بطرق عربية مثل `أضف` و`رتب` و`مفاتيح`
- **معالجة أخطاء حقيقية**: `جرب / باستثناء / اخيرا / ارفع` مع رسائل عربية
- **وحدات جاهزة**: `رياضيات`، `وقت`، `ملفات`، `جيسون`
- **امتداد VS Code**: تلوين بناء الجملة ومقتطفات كود للملفات `.عربي`
- **مفسر تفاعلي (REPL)** لتجربة الأوامر فورًا
- **رسائل خطأ تُعلّمك**: رقم السطر + محتواه + إشارة إلى موضع الخطأ + اقتراح الحل

## المتطلبات والتشغيل

تحتاج فقط **بايثون 3.8 أو أحدث**، لا شيء آخر:

```bash
# استنساخ المشروع
git clone https://github.com/CTO-DRS/arabi-lang.git
cd arabi-lang

# تشغيل ملف
python3 arabi.py examples/01_مرحبا_بالعالم.عربي

# فتح المفسر التفاعلي
python3 arabi.py

# تنفيذ كود مباشر
python3 arabi.py -c 'اطبع("مرحبا!")'
```

امتداد ملفات اللغة هو **`.عربي`**.

## دليل اللغة

### التعليقات

```text
# هذا تعليق، يبدأ بعلامة # وينتهي بنهاية السطر
اطبع("الكود يعمل")  # ويمكن أن يكون بجانب الكود
```

### المتغيرات

لا حاجة لإعلان النوع، الإسناد ينشئ المتغير:

```text
الاسم = "أحمد"
العمر = ٢٥
الطول = ١.٧٥
متاح = صح
```

### العمليات الحسابية

| العملية | المعامل | مثال | النتيجة |
|---------|---------|------|---------|
| الجمع | `+` | `٥ + ٢` | `7` |
| الطرح | `-` | `٥ - ٢` | `3` |
| الضرب | `*` | `٥ * ٢` | `10` |
| القسمة | `/` | `١٠ / ٢` | `5` |
| باقي القسمة | `%` | `١٠ % ٣` | `1` |
| الأس | `**` | `٢ ** ٣` | `8` |

القسمة تعطي عددًا صحيحًا إذا كانت النتيجة صحيحة (`١٠ / ٢` تعطي `5`)، وعددًا عشريًا غير ذلك (`٧ / ٢` تعطي `3.5`).

### المقارنات والمنطق

```text
٥ > ٣          # صح
الاسم == "أحمد"
العدد != ١٠
أ <= ب

# المنطق
صح و خطأ       # خطأ
صح أو خطأ      # صح
ليس صح         # خطأ

# العضوية
"تفاح" في فواكه
"عنب" ليس في فواكه
```

### الشروط

```text
لو الدرجة >= ٩٠:
    اطبع("ممتاز")
وإلا إذا الدرجة >= ٨٠:
    اطبع("جيد جدًا")
وإلا:
    اطبع("حاول مرة أخرى")
```

### الحلقات

```text
# لكل — المرور على تسلسل
لكل عدد في مدى(١، ٦):
    اطبع(عدد)

# طالما — تكرار بشرط
طالما الرصيد > ٠:
    الرصيد -= ١٠

# كسر — خروج من الحلقة
# استمر — تخطي الدورة الحالية
```

### بدّل / حالة / افتراض

بديل أنظف لسلسلة طويلة من `لو / وإلا إذا` عند مقارنة قيمة واحدة بقيم متعددة:

```text
بدّل يوم
حالة "السبت":
    اطبع("عطلة")
حالة "الأحد":
    اطبع("عطلة أيضًا")
افتراض:
    اطبع("يوم عمل")
```

- تُقارن قيمة `بدّل` بالحالات **بالترتيب** حتى أول تطابق، وتُنفّذ كتلتها وحدها (لا تساقط مثل C)
- كتلة `افتراض` تُنفّذ إن لم تتطابق أي حالة، وهي اختيارية
- قيم الحالات يمكن أن تكون أي تعبير: نصوص، أعداد، أو حسابات
- `كسر` داخل `بدّل` داخل حلقة يخرج من الحلقة نفسها

### الدوال

```text
دالة مساحة_المستطيل(العرض، الارتفاع):
    أعد العرض * الارتفاع

دالة ترحيب(الاسم):
    اطبع("مرحبا", الاسم)

المساحة = مساحة_المستطيل(٥، ٨)
```

الإسناد المتعدد مفيد لتبديل القيم:

```text
أ، ب = ١، ٢
أ، ب = ب، أ      # تبديل
```

#### القيم الافتراضية والمعاملات بالاسم

يمكن إعطاء المعاملات قيمًا افتراضية، واستدعاء الدالة بالأسماء لقراءة أوضح:

```text
دالة فاتورة(الصنف، الكمية = ١، سعر = ١٠):
    أعد الصنف + ": " + نص(الكمية * سعر)

اطبع(فاتورة("قلم"))                  # تستخدم الافتراضيات
اطبع(فاتورة("دفتر"، ٣))               # الكمية موضعيًا
اطبع(فاتورة("حاسبة"، سعر = ١٥٠))     # بالاسم — الترتيب لا يهم
```

#### الدوال السهمية

دالة على سطر واحد بتعبير واحد، تُخزن في متغير وتُمرر كقيمة:

```text
ضاعف = دالة(س) => س * ٢
اطبع(ضاعف(٢١))                    # 42

عمليات = [دالة(س) => س + ١، دالة(س) => س * ١٠]
اطبع(عمليات[١](٥))                # 50

# تُمرر كمعامل إلى دالة أخرى
دالة طبق(قيمة، تحويل):
    أعد تحويل(قيمة)

اطبع(طبق(٥، دالة(س) => س * س))    # 25
```

#### خريطة / مرشّح / اختزل

دوال جاهزة ذات ترتيب أعلى تعالج قائمة كاملة بدالة تحددها أنت:

```text
أعداد = [١، ٢، ٣، ٤]

خريطة(دالة(س) => س * س، أعداد)         # [1، 4، 9، 16]
مرشّح(دالة(س) => س % ٢ == ٠، أعداد)    # [2، 4]
اختزل(دالة(أ، ب) => أ + ب، أعداد)      # 10 — تطوي القائمة لقيمة
اختزل(دالة(أ، ب) => أ + ب، أعداد، ١٠٠) # 110 — مع قيمة بداية

# تتعامل مع النصوص والمدى أيضًا
خريطة(دالة(ح) => كبير(ح)، "أب")        # [أ، ب]
```

### القوائم

```text
فواكه = ["تفاح"، "موز"، "برتقال"]

فواكه[٠]          # "تفاح" — الفهرسة تبدأ من صفر
فواكه[-١]         # "برتقال" — من النهاية
فواكه[٠:٢]        # تقطيع: ["تفاح"، "موز"]
طول(فواكه)        # 3

# الطرق الجاهزة
فواكه.أضف("عنب")       # إضافة عنصر
فواكه.أزل("موز")       # حذف قيمة
فواكه.رتب()            # ترتيب
فواكه.اعكس()           # عكس
فواكه.انبثق()          # سحب آخر عنصر
فواكه.عدد_التكرار("تفاح")
فواكه.انسخ()           # نسخة جديدة
```

### القواميس

```text
شخص = {"الاسم": "خالد"، "العمر": ٣٠}

شخص["الاسم"]          # "خالد"
شخص["الوظيفة"] = "مهندس"   # إضافة مفتاح جديد

# الطرق الجاهزة
شخص.مفاتيح()          # ["الاسم"، "العمر"، "الوظيفة"]
شخص.قيم()             # ["خالد"، ٣٠، "مهندس"]
شخص.عناصر()           # [["الاسم"، "خالد"]، ...]
شخص.احذف("العمر")
```

المرور على المفاتيح والقيم معًا بالتفكيك:

```text
لكل مفتاح، قيمة في شخص.عناصر():
    اطبع(مفتاح، "=>", قيمة)
```

### معالجة الأخطاء

```text
جرب:
    النتيجة = ١٠ / ٠
باستثناء:
    اطبع("لا يمكن القسمة على صفر")
اخيرا:
    اطبع("هذا السطر يُنفذ دائمًا")

# رمي خطأ مخصص
لو العمر < ٠:
    ارفع "العمر لا يمكن أن يكون سالبًا"
```

### البرمجة الكائنية

عرّف أصنافك بكلمة `صنف`، وادفع إلى خصائص الكائن عبر `هذا`:

```text
صنف حيوان:
    دالة إنشاء(اسم):
        هذا.اسم = اسم

    دالة صوت():
        أعد "..."

ك = حيوان("أسد")
اطبع(ك.اسم)
اطبع(ك.صوت())
```

**الوراثة** بكلمة `من`، واستدعاء طرق الأب عبر `الأصل`:

```text
صنف قطة من حيوان:
    دالة صوت():
        أعد "مياو"

صنف موظف من شخص:
    دالة إنشاء(اسم، راتب):
        الأصل.إنشاء(هذا، اسم)          # استدعاء منشئ الأب
        هذا.راتب = راتب
```

- المنشئ هو الطريقة المسماة `إنشاء` وتُستدعى تلقائيًا عند إنشاء الكائن
- الطرق والثوابت تُورّث تلقائيًا، ويمكن إعادة تعريفها في الصنف الابن
- ثوابت الصنف تُعرّف مباشرة في جسمه وتُقرأ من الصنف أو الكائن

### الوحدات الجاهزة

```text
استورد رياضيات
اطبع(رياضيات.جذر(١٦))       # 4.0
اطبع(رياضيات.بي)             # 3.14159...

استورد وقت
وقت.نوم(١)                   # سكون ثانية
اطبع(وقت.زمن())              # الزمن الحالي بالثواني
```

#### وحدة ملفات

كتابة وقراءة الملفات النصية مباشرة:

```text
ملفات.اكتب("ملاحظات.txt"، "سطر أول\n")   # يكتب فوق المحتوى
ملفات.أضف("ملاحظات.txt"، "سطر ثانٍ\n")   # يضيف إلى النهاية
اطبع(ملفات.اقرأ("ملاحظات.txt"))            # يقرأ المحتوى كاملًا
اطبع(ملفات.أسطر("ملاحظات.txt"))            # [سطر أول، سطر ثانٍ]
اطبع(ملفات.موجود("ملاحظات.txt"))           # صح
ملفات.احذف("ملاحظات.txt")                  # حذف الملف
```

#### وحدة جيسون

حفظ البيانات وتبادلها بصيغة JSON الشائعة — تحافظ على النصوص العربية:

```text
طالب = {"الاسم": "نورة"، "العمر": ٢٥، "مواد": ["رياضيات"]}
نص_جيسون = جيسون.نص(طالب)              # حفظ بصيغة JSON
ملفات.اكتب("طالب.json"، نص_جيسون)

المعاد = جيسون.حلل(ملفات.اقرأ("طالب.json"))
اطبع(المعاد["الاسم"])                   # نورة
```

- `حلل` يقبل JSON القياسي، ويتسامح مع الأرقام العربية `٢٥` والفاصلة `،`
- `نص` يرفع خطأً واضحًا إن حاولت تحويل قيمة غير قابلة للحفظ

### الوحدات الخاصة (ملفات .عربي)

نظم مشروعك في ملفات متعددة واستوردها — ضع ملف `هندسة.عربي` بجانب برنامجك (أو في مجلد `وحدات/`):

```text
# ملف: هندسة.عربي
ط = ٣.١٤

دالة مساحة_الدائرة(نق):
    أعد ط * نق * نق
```

ثم استورده بثلاث صيغ:

```text
# ١) استيراد كامل — الوحدة كائن يحوي كل ما فيها
استورد هندسة
اطبع(هندسة.مساحة_الدائرة(٥))

# ٢) استيراد أسماء محددة
من هندسة استورد مساحة_الدائرة
اطبع(مساحة_الدائرة(٢))

# ٣) استيراد بمسار صريح
استورد "وحدات/هندسة.عربي"
```

- الوحدة تُنفّذ **مرة واحدة** مهما تكرر الاستيراد (تخزين مؤقت)
- الاستيراد الدائري (أ يستورد ب يستورد أ) يُكشف ويرفع خطأً واضحًا
- داخل الوحدة تتوفر كل الجاهزات (`اطبع`، `رياضيات`، …)، ومتغيراتها معزولة عن البرنامج المستورد

## الدوال الجاهزة

| الدالة | الوظيفة | مثال |
|--------|---------|------|
| `اطبع(...)` | طباعة القيم مفصولة بمسافة | `اطبع("أ"، ٥)` |
| `طول(س)` | طول نص/قائمة/قاموس | `طول([١، ٢])` → `2` |
| `مدى(أ، ب، خطوة)` | توليد تسلسل أعداد | `مدى(٥)` أو `مدى(١٠، ٠، -٢)` |
| `إدخال(رسالة)` | قراءة إدخال المستخدم | `عدد(إدخال("أدخل: "))` |
| `عدد(ق)` | تحويل إلى عدد صحيح | `عدد("٤٢")` → `42` |
| `عشري(ق)` | تحويل إلى عدد عشري | `عشري("٣.٥")` → `3.5` |
| `نص(ق)` | تحويل إلى نص | `نص(٣٠)` → `"30"` |
| `قائمة(ق)` | تحويل إلى قائمة | `قائمة(مدى(٣))` |
| `قاموس()` | قاموس فارغ | `قاموس()` |
| `جمع(قائمة)` | مجموع الأعداد | `جمع([١، ٢، ٣])` → `6` |
| `أكبر(...)` / `أصغر(...)` | أكبر/أصغر قيمة | `أكبر([٤، ٩])` → `9` |
| `مطلق(ع)` | القيمة المطلقة | `مطلق(-٥)` → `5` |
| `تقريب(ع، ن)` | تقريب العدد | `تقريب(٣.٧)` → `4` |
| `عشوائي(أ، ب)` | عدد عشوائي بين عددين | `عشوائي(١، ٦)` |
| `اختر(تسلسل)` | عنصر عشوائي | `اختر(["ورق"، "حجر"])` |
| `خريطة(د، ق)` | تطبيق دالة على كل عنصر | `خريطة(دالة(س) => س * ٢، [١، ٢])` |
| `مرشّح(د، ق)` | العناصر التي حققت الشرط | `مرشّح(دالة(س) => س > ٥، ق)` |
| `اختزل(د، ق، ب؟)` | طي القائمة إلى قيمة واحدة | `اختزل(دالة(أ، ب) => أ + ب، ق)` |
| `نوع(ق)` | اسم نوع القيمة | `نوع("ن")` → `"نص"` |
| `رتّب(قائمة)` | قائمة مرتبة جديدة | `رتّب([٣، ١])` → `[1، 3]` |

## الاختبارات

المشروع مغطى بـ160 اختبارًا يغطي المحلل اللفظي والنحوي والمفسر والبرمجة الكائنية والوحدات والمعاملات بالاسم والدوال السهمية وبدّل/حالة والدوال ذات الترتيب الأعلى وملفات وجيسون ورسائل الأخطاء وجميع الأمثلة:

```bash
python3 -m unittest discover -s tests -v
```

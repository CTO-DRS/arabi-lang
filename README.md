# عربي — لغة برمجة عربية بالكامل

**عربي** لغة برمجة كاملة صُممت لتكتب بها الكود بالعربية من أوله لآخره: متغيرات، شروط، بدّل/حالة، حلقات، دوال، سلاسل منسقة، قوائم، قواميس، معالجة أخطاء، برمجة كائنية، ووحدات قابلة للاستيراد — كل ذلك بكلمات مفتاحية عربية ورسائل خطأ عربية واضحة تخبرك بالضبط أين المشكلة وما الحل.

ومنذ الإصدار 1.5 أصبحت اللغة متكاملة الأركان: **تعداد**، **خصائص محسوبة**، **تحميل عوامل** على الكائنات، **أخطاء مخصصة** ترث `استثناء`، **تعبير ثلاثي**، وأربع وحدات قياسية جديدة (عشوائية، نظام، تنظيم، شبكة) ووحدة **تحويل** حصرية تُفقط الأرقام إلى كلمات عربية.

وفي الإصدار 1.6 اكتمل **النظام البيئي**: إطار اختبارات داخل اللغة (وحدة `اختبارات`)، خوادم ويب حقيقية (وحدة `خادم`)، مدير حزم (`--ثبت` / `--حزم`) مع مجلد `مكتبات/`، منسق كود (`--نسق`)، فاحص مشكلات (`--افحص`)، مولد توثيق (`--وثق`)، ومفسر تفاعلي بسجل أوامر وإكمال تلقائي.

وفي الإصدار 1.7 اكتملت ميزات اللغة المتقدمة: **المولدات** بكلمة `أنتج` (قيم تباعًا بكفاءة ذاكرة)، **المزخرفات** بعلامة `@` (مثل بايثون تمامًا)، و**الوراثة المتعددة** بترتيب حل طرق C3، مع ثلاث وحدات قياسية جديدة: `قاعدة` (SQLite كاملة)، `ترميز` (Base64 والبصمات)، و`جداول` (ملفات CSV).

وفي الإصدار 1.8 جاء **التزامن والتجريد**: **الواجهات** بكلمة `واجهة` (عقد مجرد تلتزم به الأصناف مع تحقق عند الإنشاء)، **المعاملات المتغيرة** `...الاسم` و**التفكيك** `...قائمة` في الاستدعاءات والقوائم، ووحدة `خيوط` للتنفيذ المتوازي بذاكرة مشتركة (شغّل/قفل/طابور).

وفي الإصدار 1.9 جاءت **التعبيرية**: **مطابقة الأنماط** بكلمة `طابق` (أنماط حرفية وبدائل بأو والتقاط قيم وحرّاس `إن شرط` وتفكيك قوائم بـ`...البقية` وقواميس ومسارات قيم للتعدادات)، **السلاسل الخام** `خ"..."` بلا معالجة هروب (مثالية للتعبيرات النمطية)، ووحدة `تواريخ` الكاملة (إنشاء وتنسيق وتحليل وفروق وأيام أسبوع بالعربية).

وفي الإصدار 1.10 جاءت **بيئة المطوّر**: **بروتوكول التكرار المخصص** — أي صنف يعرّف `تالٍ` (مع `أول` الاختيارية) يعمل مباشرة مع `لكل` و`في` والنشر `...`، ووحدة `إحصاء` للتحليل الوصفي (معدل/وسيط/منوال/تباين/انحراف/مدى)، و**خادم اللغة (LSP)** الكامل (`--لغة`) الذي يوفر التشخيص اللحظي والإكمال الذكي والتلميحات ورموز المستند والانتقال للتعريف داخل أي محرر يدعم LSP.

وفي الإصدار 1.11 جاء **الأداء والتعبيرية**: **فهم القوائم والقواميس** — بناء متتاليات في سطر واحد بصيغة `[تعبير لكل س في متتالية إن شرط]` مع التفكيك وعبارات متتالية — و**الكود الوسيط (Bytecode)** الذي يترجم شجرة البرنامج إلى صيغة مخزنة في `__بايت__/*.بيت` ويحمّلها في التشغيلات التالية متجاوزًا التحليل اللفظي والنحوي (تسريع ٥ أضعاف فأكثر للبرامج الكبيرة)، تلقائيًا للبرنامج الرئيسي وكل وحداته المستوردة.

وفي الإصدار 1.12 اكتمل **النظام البيئي ببندته الأخيرة**: **سجل الحزم** — مدير حزم كامل بأمر `حزمة` (تثبيت/إزالة/قائمة/بحث/تحديث) بفهرس مركزي قابَل للاستبدال، ونسخ دلالية بقيود `^` و`~` و`>=`، وتبعيات تُحل تلقائيًا بكشف الدورات، وملف قفل `قفل.json`، وحزم تُثبت في `حزم/` ويستوردها المفسّر تلقائيًا.

وفي الإصدار 1.13 صار التنفيذ نفسه أسرع: **الدولاب الافتراضي (Virtual Machine)** — المفسّر يترجم أجسام الدوال عند أول استدعاء إلى تعليمات بايت-كود تنفذها حلقة دولاب واحدة (تسريع يصل إلى ٢.٨× في الحلقات الحسابية و٢× في التعاود)، وكل جملة أو تعبير خارج المجموعة السريعة يعود للممسح الشجري الأصلي تلقائيًا — فالدلالات والأخطاء وأرقام الأسطر متطابقة دائمًا، وعلم `--لا-دولاب` يعيدك للمسار الأصلي متى شئت.

وفي الإصدار 1.14 اكتملت خارطة الطريق: **الملف التنفيذي المستقل** — المفسّر كله (المحللان والمفسر والدولاب والوحدات الثماني عشر ومدير الحزم وخادم اللغة) في ملف واحد قابل للتنفيذ يعمل **بلا حاجة لبايثون** على جهاز المستخدم، جاهز للتحميل من صفحة الإصدارات، وقابل لإعادة البناء على أي نظام بأمر واحد `scripts/بناء_التنفيذي.sh`.

وفي الإصدار 1.15 جاء **غير المتزامن**: `غير متزامنة دالة` تعمل في خيط مستقل فور استدعائها ويعيد الاستدعاء **مهمة** تنتظرها بكلمة `انتظر` — مع `انتظر_الجميع` لتجميع النتائج و`سباق` لأول من ينجز و`انتظر_زمن` لنوم المهمة — وأضافت وحدة `شبكة` دالة `تنزيل` لتحميل الملفات (تنزيلات متوازية بمهام غير متزامنة؟ سطران!).

وفي الإصدار 1.16 صار التوزيع والتشغيل الكثيف أسهل من أي وقت: **تجمع الخيوط** `تجمع(٤)` ينفذ أعمالك على عدد محدود من الخيوط المُعاد استخدامها (قدّم/إنهاء/حجم — ويحترم دلالات غير المتزامن بالكامل)، و**التوزيع عبر pip** (`pip install arabi-lang` ثم الأمر `arabi`)، و**سير إصدارات آلي** يبني التنفيذي المستقل على لينكس وويندوز وماك ويؤسس حزمة بايثون مع كل وسم جديد.

وفي الإصدار 1.17 كسرت الخيوط حدودها: **توازي العمليات** — وحدة `عمليات` تشغل أعمالك في **معالجات منفصلة حقيقية** بذاكرة معزولة تتجاوز قفل التفسير العالمي لبايثون (GIL)، فتستفيد الأعمال الحسابية الخالصة من كل أنوية الجهاز. الواجهة نفسها التي تعرفها: `شغّل(دالة، وسائط)` و`تجمع(عدد)` و`قدّم` و`انتظر` و`انتظر_الجميع` — والدوال والأصناف والكائنات والأخطاء المخصصة تعبر حدود العملية بهويتها كاملة.

وفي الإصدار 1.18 كسرت الجهاز الواحد حدوده: **الحوسبة الموزعة** — وحدة `موزعة` توزع مهامك على **عدة أجهزة عبر الشبكة الحقيقية**: `موزع(منفذ)` يبدأ خادم توزيع يستقبل اتصالات العمالة، و`عامل(المضيف، المنفذ)` يربط عاملاً بأي جهاز (أو الأمر الجاهز `arabi --عامل المضيف:المنفذ`)، و`قدّم` تعيد مهمة تنتظرها بـ`انتظر` و`انتظر_الجميع` و`سباق` كما اعتدت — وانقطاع عامل يعيد أعماله للطابور فتخدمها عمالة أخرى، ولا تضيع مهمة.

وفي الإصدار 1.19 حصنت ما بنيت: **الأمان والتشفير** — وحدة `تشفير` تجلب حماية المكتبة القياسية إلى لغتك بلا أي تبعيات: بصمات قوية (هش/هش512 بست خوارزميات)، وتوقيع رسائل `هوماك`، ومقارنة زمن ثابت `مقارنة_آمنة` تفشل في التوقيت، ومفاتيح عشوائية آمنة تشفيريًا (`مفتاح_آمن` و`رمز_آمن` و`عدد_آمن`)، وتشفير كلمات المرور بـ PBKDF2 (`شفر_كلمة` و`تحقق_كلمة` — الملح عشوائي لكل كلمة والبصمة لا تُخزَّن أبدًا) واشتقاق المفاتيح `مشتق` — والموزع الموزع (1.18) صار يقبل مفتاحًا سريًا ثالثًا فيصبح لا عامل يُسجّل إلا بتوقيع تحدٍّ عشوائي بالمفتاح المشترك: `موزع(0، "0.0.0.0"، تشفير.مفتاح_آمن())`.

بنيت اللغة بلغة بايثون (بدون أي مكتبات خارجية) كمفسر ينفذ الكود سطرًا بسطر، بطريقة مشابهة لفلسفة بايثون نفسها: بسيطة، مقروءة، والكتل تُحدد بالمسافات البادئة.

```text
دالة مضروب(ن):
    لو ن <= ١:
        أعد ١
    أعد ن * مضروب(ن - ١)

اطبع("مضروب ٦ =", مضروب(٦))
```

## المميزات

- **صياغة عربية بالكامل**: `لو`، `وإلا إذا`، `وإلا`، `بدّل`، `طالما`، `لكل`، `دالة`، `أعد`، `صح/خطأ`…
- **أرقام بالصيغتين**: استخدم `٤٢` أو `42` كما تشاء، والفاصلة `،` أو `,`
- **كتل بمسافات بادئة** مثل بايثون — لا أقواس معقوصة تشوش الكود
- **دوال كاملة**: معاملات، إرجاع قيم، تعاود، وإغلاق (Closures)
- **قيم افتراضية ومعاملات بالاسم (جديدة في 1.2)**: `دالة فاتورة(الصنف، سعر = ١٠)` واستدعاء بـ`فاتورة("قلم"، سعر = ٢٠)`
- **دوال سهمية (جديدة في 1.2)**: `ضاعف = دالة(س) => س * ٢` — دالة على سطر واحد تُمرر كقيمة
- **وحدات من ملفاتك (جديدة في 1.2)**: `استورد هندسة` أو `من هندسة استورد مساحة` — انظم مشروعك في ملفات `.عربي`
- **بدّل/حالة/افتراض (جديد في 1.3)**: تفرع أنظف من سلسلة `لو` الطويلة عند مقارنة قيمة واحدة
- **خريطة/مرشّح/اختزل (جديدة في 1.3)**: دوال ترتيب أعلى جاهزة تعمل مع السهميات
- **ملفات وجيسون (جديدة في 1.3)**: وحدة `ملفات` للكتابة والقراءة، ووحدة `جيسون` للحفظ والتبادل
- **سلاسل منسقة (جديدة في 1.4)**: `ق"مرحبا {الاسم}، الناتج {أ + ب}"` — حقن أي تعبير داخل النص مباشرة
- **نصوص متعددة الأسطر (جديدة في 1.4)**: ثلاث علامات اقتباس للنصوص الطويلة بلا هروب
- **طرق نصية أغنى (جديدة في 1.4)**: `أوجد`، `يحتوي`، `عدد_التكرار`، `اعكس`
- **تعداد (جديد في 1.5)**: `تعداد يوم: السبت، الأحد…` — ثوابت مسماة بقيم تلقائية أو صريحة
- **خصائص محسوبة (جديدة في 1.5)**: `خاصية المساحة:` — تُقرأ بلا أقواس وتُحسب عند كل وصول
- **تحميل العوامل (جديد في 1.5)**: عرّف `اجمع` و`اطرح` و`يساوي` و`نص` و`طول` و`فهرس` في أصنافك فتدعم `+` و`-` و`==` والطباعة والفهرسة
- **أخطاء مخصصة (جديدة في 1.5)**: `صنف خطأ_دفع من استثناء` ثم `باستثناء هـ:` لربط الخطأ وقراءة `هـ.رسالة`
- **تعبير ثلاثي (جديد في 1.5)**: `النتيجة = لو العمر >= ١٨: "بالغ" وإلا "طفل"`
- **عالمي / تحقق / احذف (جديدة في 1.5)**: أدوات نضج كاملة للتحكم في النطاق والتحقق وحذف المتغيرات
- **خمس وحدات قياسية جديدة (جديدة في 1.5)**: `عشوائية`، `نظام`، `تنظيم` (تعبيرات نمطية)، `شبكة` (طلبات HTTP)، و`تحويل` (تفقيط الأرقام إلى كلمات عربية — حصري!)
- **المولدات (جديدة في 1.7)**: `أنتج` — دوال تنتج قيمًا تباعًا عند الطلب، تتكرر بـ`لكل` وتُحوّل بـ`قائمة()` وتتقدم يدويًا بـ`التالي()`
- **المزخرفات (جديدة في 1.7)**: `@اسم` فوق تعريف الدالة — قِس زمن التنفيذ، خزّن النتائج، وسّع دوالك بلا تعديلها
- **الوراثة المتعددة (جديدة في 1.7)**: `صنف بطة من طائر، سباح` بترتيب حل طرق C3 (كما في بايثون) مع `الأصل` المرتبط تلقائيًا
- **قواعد بيانات SQLite (جديدة في 1.7)**: وحدة `قاعدة` — أنشئ جداول وأدرج واستعلم بمعاملات آمنة من الحقن
- **ترميز وبصمات (جديدة في 1.7)**: وحدة `ترميز` — `شفّر64` و`فك64` و`هش256` و`هش1`
- **جداول CSV (جديدة في 1.7)**: وحدة `جداول` — اقرأ واكتب وحلل ملفات البيانات بفواصل مخصصة
- **الواجهات (جديدة في 1.8)**: `واجهة شكل:` — طرق مجردة بلا جسم يجب تنفيذها، وتنفيذ افتراضي يورث، وثوابت مشتركة، والتحقق عند `إنشاء` الكائن برسائل عربية دقيقة
- **المعاملات المتغيرة (جديدة في 1.8)**: `دالة مجموع(...أرقام)` — اجمع الوسائط الزائدة في قائمة (تعمل مع الدوال والسهميات والطرق)
- **التفكيك (جديد في 1.8)**: `مجموع(...قائمة)` يفتّ القائمة إلى وسائط، و`[١، ...أخرى، ٩]` يدمج القوائم والنصوص والمدى والمولدات
- **تنفيذ متوازي (جديد في 1.8)**: وحدة `خيوط` — `شغّل` و`انتظر_الكل` و`قفل` (احجز/افرح/محاولة) و`طابور` آمن للرسائل
- **مطابقة الأنماط (جديدة في 1.9)**: `طابق قيمة` ثم `حالة نمط:` — حرفيات، بدائل بأو، التقاط، الرمز البديل `_`، حرّاس `إن شرط`، تفكيك قوائم `[أ، ...البقية]`، قواميس `{الاسم: ن}`، ومسارات قيم للتعدادات
- **الالتقاط المتساوي (جديد في 1.9)**: التقاط مكرر داخل النمط `[أ، أ]` يعني "العنصران متساويان"
- **السلاسل الخام (جديدة في 1.9)**: `خ"\d+"` — الشرطة المائلة المعكوسة حرف عادي، تكتب أنماط التنظيم كما هي بلا مضاعفة
- **وحدة تواريخ (جديدة في 1.9)**: `الآن` و`أنشئ` و`حلل` و`فرق` و`أضف` و`يوم_الأسبوع` بأسماء أيام عربية، مع طرق السنة والشهر والنسق
- **بروتوكول التكرار المخصص (جديد في 1.10)**: صنف يعرّف `تالٍ()` يصبح قابلًا للتكرار بـ`لكل` — وعودة `ولا شيء` تنهي التكرار، و`أول()` الاختيارية تعيد مؤشرًا جديدًا فيكل دورة
- **`في` والنشر على الكائنات (جديد في 1.10)**: `س في كائن` تمر على عناصر الكائن بتالٍ إن لم يعرّف `يحتوي`، و`...كائن` يفتّ عناصره في القوائم والاستدعاءات
- **وحدة إحصاء (جديدة في 1.10)**: `معدل` و`وسيط` و`منوال` و`تباين` و`انحراف` و`مدى` — تحليل وصفي جاهز بأسماء عربية
- **خادم اللغة LSP (جديد في 1.10)**: `python arabi.py --لغة` — تشخيص لحظي، إكمال ذكي (بعد النقطة يفهم الوحدات والأصناف ويستدل على صنف المتغيرات)، تلميحات توثيق، رموز المستند، والانتقال إلى التعريف
- **فهم القوائم والقواميس (جديد في 1.11)**: `[س * س لكل س في مدى(10) إن س % 2 == 0]` و`{ن: طول(ن) لكل ن في أسماء}` — تحويل وترشيح وتفكيك وعبارات لكل متتالية، بنطاق مستقل لا يسرّب متغيراته
- **الكود الوسيط (جديد في 1.11)**: تحميل فوري من `__بايت__/*.بيت` عند صلاحية الذاكرة، إبطال تلقائي عند أي تعديل، وعلمان `--بايت` للترجمة فقط و`--لا-بايت` للتعطيل
- **سجل الحزم (جديد في 1.12)**: `python3 arabi.py حزمة تثبيت اسم_الحزمة` — فهرس مركزي وتبعيات تُحل تعاوديًا وملف قفل `قفل.json`، والاستيراد من `حزم/` تلقائي
- **نسخ دلالية وقيود (جديد في 1.12)**: `>=1.0.0` و`^1.2.3` و`~1.2.3` و`*` — مطابقة semver مع كشف التبعيات الدائرية والتعارضات برسائل عربية
- **الدولاب الافتراضي (جديد في 1.13)**: ترجمة أجسام الدوال إلى بايت-كود تنفيذي بذاكرة على كل دالة — تسريع ٢.٨× للحلقات و٢× للتعاود مع احتياط شفاف للممسح الشجري وعلم `--لا-دولاب`
- **تكافؤ مضمون (جديد في 1.13)**: كل الاختبارات والقياسات تنفذ بالوضعين وتقارن — نفس المخرجات حرفيًا ونفس الأخطاء بنصوصها وأسطرها
- **ملف تنفيذي مستقل (جديد في 1.14)**: المفسّر كله في ملف واحد `عربي` يعمل بلا بايثون — جاهز للتحميل من الإصدارات وقابل لإعادة البناء بأمر واحد على أي نظام
- **تكييف تلقائي للنسخة التنفيذية (جديد في 1.14)**: `--نسخة` يعرض «تنفيذي مستقل» ورسائل الاستخدام تستخدم `./عربي` — كل الأعلام والأدوات والوحدات تعمل كما هي
- **دوال غير متزامنة (جديد في 1.15)**: `غير متزامنة دالة جلب(رابط):` — الاستدعاء يشغّلها فورًا في خيط مستقل ويعيد **مهمة** تنتظرها بـ`انتظر مهمة`
- **مجمّعات مهام (جديد في 1.15)**: `انتظر_الجميع([م١، م٢])` تجمع النتائج بترتيبها، و`سباق([...])` تعيد أول مهمة تنجز، و`مهمة.جاهز()` و`نتيجة()` و`الخطأ()` لفحص فوري
- **كلمة انتظر موحّدة وسياقية (جديد في 1.15)**: `انتظر` تعمل على المهام والخيوط معًا — وكلمة عادية أيضًا: ما يكسر `خيط.انتظر()` ولا أي معرف يحمل الاسم
- **تنزيل ملفات (جديد في 1.15)**: `شبكة.تنزيل(رابط، مسار، مهلة؟)` — تنزيل ثنائي آمن يعيد عدد البايتات، ويتكامل مع غير المتزامن لتنزيلات متوازية
- **تجمع خيوط محدود (جديد في 1.16)**: `تجمع(٤)` — عدد ثابت من الخيوط المُعاد استخدامها: `قدّم(دالة، معاملات)` تعيد مهمة، و`إنهاء()` تنتظر تصفية المقدَّم، وحد التزامن محفوظ تلقائيًا
- **توزيع عبر pip (جديد في 1.16)**: `pip install arabi-lang` ثم استخدم الأمر `arabi` أو `python -m arabi` — وثنائيات مستقلة لويندوز وماك تبني آليًا مع كل إصدار
- **برمجة كائنية**: `صنف`، `هذا`، الوراثة بـ`من`، واستدعاء الأب بـ`الأصل`
- **هياكل بيانات جاهزة**: قوائم وقواميس بطرق عربية مثل `أضف` و`رتب` و`مفاتيح`
- **معالجة أخطاء حقيقية**: `جرب / باستثناء / اخيرا / ارفع` مع رسائل عربية
- **توازي عمليات حقيقي (جديد في 1.17)**: `عمليات.شغّل(دالة، وسائط)` يشغل العمل في معالج منفصل بذاكرة معزولة يتجاوز GIL، و`عمليات.تجمع(عدد)` يوزع المهام على تجمع عمليات يُعاد استخدامه — والدوال بتعاودها وإغلاقها والأصناف والكائنات والأخطاء المخصصة تعبر العمليات شفافة
- **حوسبة موزعة عبر الشبكة (جديد في 1.18)**: `موزعة.موزع(منفذ)` خادم توزيع و`موزعة.عامل(المضيف، المنفذ)` عامل يخدم من أي جهاز (أو `arabi --عامل المضيف:المنفذ`) — إطارات موسومة بالطول عبر TCP، وانقطاع العامل يعيد أعماله للطابور، و`انتظر_العمال` للانتظار الحتمي
- **أمان وتشفير (جديد في 1.19)**: وحدة `تشفير` — بصمات `هش` بست خوارزميات وتوقيع `هوماك` ومقارنة زمن ثابت ومفاتيح ورموز آمنة و`شفر_كلمة`/`تحقق_كلمة` بـ PBKDF2 واشتقاق `مشتق` — ومصادقة اختيارية للموزعة بمفتاح مشترك: لا عامل يُسجّل إلا بتوقيع HMAC على تحدٍّ عشوائي
- **تسلسل تزامني متكامل**: خيوط (1.8) ← غير متزامن (1.15) ← تجمع خيوط (1.16) ← عمليات (1.17) ← موزع على الأجهزة (1.18) — واجهة انتظار واحدة (`انتظر` و`انتظر_الجميع` و`سباق`) على الخمسة
- **وحدات جاهزة (20 وحدة)**: `رياضيات`، `وقت`، `ملفات`، `جيسون`، `عشوائية`، `نظام`، `تنظيم`، `شبكة`، `تحويل`، `اختبارات`، `خادم`، `قاعدة`، `ترميز`، `جداول`، `خيوط`، `تواريخ`، `إحصاء`، `عمليات`، `موزعة`، `تشفير`
- **امتداد VS Code**: تلوين بناء الجملة ومقتطفات كود للملفات `.عربي`
- **أداة فحص الصياغة (جديدة في 1.5)**: `python3 arabi.py --تحقق ملف.عربي` بلا تنفيذ
- **إطار اختبارات داخل اللغة (جديد في 1.6)**: وحدة `اختبارات` بدوال `يساوي` و`يصح` و`يرفع` و`ملخص`
- **خوادم ويب حقيقية (جديدة في 1.6)**: وحدة `خادم` — `خادم.ابدأ(المنفذ، معالج)` يخدم صفحات وواجهات API
- **أدوات النظام البيئي (جديدة في 1.6)**: `--نسق` منسق كود، `--افحص` فاحص مشكلات، `--وثق` مولد توثيق، `--ثبت`/`--حزم` مدير حزم بمجلد `مكتبات/`
- **مفاتيح قواميس بلا اقتباس (جديدة في 1.6)**: `{الحالة: 200}` ≡ `{"الحالة": 200}`
- **نصوص منسقة متعددة الأسطر (جديدة في 1.6)**: `ق"""قالب HTML كامل {متغير}"""`
- **مفسر تفاعلي (REPL)** لتجربة الأوامر فورًا
- **رسائل خطأ تُعلّمك**: رقم السطر + محتواه + إشارة إلى موضع الخطأ + اقتراح الحل

### التعليقات

```text
# هذا تعليق، يبدأ بعلامة # وينتهي بنهاية السطر
اطبع("الكود يعمل")  # ويمكن أن يكون بجانب الكود
```

### المتغيرات

لا حاجة لإعلان النوع، الإسناد ينشئ المتغير:

```text
الاسم = "أحمد"
العمر = ٢٥
الطول = ١.٧٥
متاح = صح
```

### العمليات الحسابية

| العملية | المعامل | مثال | النتيجة |
|---------|---------|------|---------|
| الجمع | `+` | `٥ + ٢` | `7` |
| الطرح | `-` | `٥ - ٢` | `3` |
| الضرب | `*` | `٥ * ٢` | `10` |
| القسمة | `/` | `١٠ / ٢` | `5` |
| باقي القسمة | `%` | `١٠ % ٣` | `1` |
| الأس | `**` | `٢ ** ٣` | `8` |

القسمة تعطي عددًا صحيحًا إذا كانت النتيجة صحيحة (`١٠ / ٢` تعطي `5`)، وعددًا عشريًا غير ذلك (`٧ / ٢` تعطي `3.5`).

### المقارنات والمنطق

```text
٥ > ٣          # صح
الاسم == "أحمد"
العدد != ١٠
أ <= ب

# المنطق
صح و خطأ       # خطأ
صح أو خطأ      # صح
ليس صح         # خطأ

# العضوية
"تفاح" في فواكه
"عنب" ليس في فواكه
```

### الشروط

```text
لو الدرجة >= ٩٠:
    اطبع("ممتاز")
وإلا إذا الدرجة >= ٨٠:
    اطبع("جيد جدًا")
وإلا:

```

### الحلقات

```text
# لكل — المرور على تسلسل
لكل عدد في مدى(١، ٦):
    اطبع(عدد)

# طالما — تكرار بشرط
طالما الرصيد > ٠:
    الرصيد -= ١٠

# كسر — خروج من الحلقة
# استمر — تخطي الدورة الحالية
```

### بدّل / حالة / افتراض

بديل أنظف لسلسلة طويلة من `لو / وإلا إذا` عند مقارنة قيمة واحدة بقيم متعددة:

```text
بدّل يوم
حالة "السبت":
    اطبع("عطلة")
حالة "الأحد":
    اطبع("عطلة أيضًا")
افتراض:
    اطبع("يوم عمل")
```

- تُقارن قيمة `بدّل` بالحالات **بالترتيب** حتى أول تطابق، وتُنفّذ كتلتها وحدها (لا تساقط مثل C)
- كتلة `افتراض` تُنفّذ إن لم تتطابق أي حالة، وهي اختيارية
- قيم الحالات يمكن أن تكون أي تعبير: نصوص، أعداد، أو حسابات
- `كسر` داخل `بدّل` داخل حلقة يخرج من الحلقة نفسها

### مطابقة الأنماط (جديدة في 1.9)

`طابق` أقوى من `بدّل`: النمط لا يقارن فقط بل **يفكك البنية ويلتقط القيم** ويربطها:

```text
طابق قائمة
حالة []:
    اطبع("فارغة")
حالة [أول، ...البقية]:
    اطبع("أولها", أول، "وبقيت", طول(البقية))
غير ذلك:
    اطبع("ليست قائمة")
```

**أنماط مدعومة:**

| النمط | يطابق | مثال |
|-------|-------|------|
| حرفية | قيمة يساويها بالضبط | `حالة ٥:` / `حالة "نص":` / `حالة -١:` |
| بدائل | أي نمط من البدائل | `حالة ١ أو ٢ أو ٣:` |
| التقاط | أي قيمة ويربطها باسم | `حالة ن:` ثم استخدام `ن` داخل الكتلة |
| الرمز البديل `_` | أي قيمة بلا ربط | `حالة _:` |
| حارس | النمط بشرط إضافي | `حالة ن إن ن > ١٠:` |
| قائمة | بنية قائمة بطول محدد | `حالة [أ، ب]:` |
| قائمة مع البقية | بادئة ثابتة والزائد يُجمع | `حالة [أ، ...البقية]:` أو `حالة [أ، ...]:` |
| التقاط متكرر | تساوي العناصر الملتقَطة | `حالة [أ، أ]:` (العنصران متساويان) |
| قاموس | مفاتيح موجودة وقيم تطابق | `حالة {الاسم: ن، العمر: ع}:` (الزائد مسموح) |
| مسار قيمة | تساوي مع تعبير (مثالي للتعدادات) | `حالة لون.أحمر:` |

مثال تكاملي — تعداد مع مطابقة القيم والحرّاس:

```text
تعداد حالة_الطلب:
    جديد
    قيد_التنفيذ
    مكتمل

طابق الطلب.الحالة
حالة حالة_الطلب.جديد:
    اطبع("ابدأ التنفيذ")
حالة حالة_الطلب.قيد_التنفيذ إن الأولوية > ٥:
    اطبع("عجّل به!")
حالة _:
    اطبع("لا حاجة لفعل شيء")
```

- روابط الالتقاط تبقى متاحة بعد انتهاء المطابقة (كما في بايثون)
- الأنماط تُجرب بالترتيب، وفشل الحارس ينقل للنمط التالي

### السلاسل الخام (جديدة في 1.9)

البادئة `خ` قبل النص تعطّل معالجة الهروب — الشرطة المائلة المعكوسة حرف عادي:

```text
عادي = "س\\ط"      # تكتب شرطتين لتحصل على شرطة
خام = خ"س\\ط"     # تكتب شرطة واحدة — الناتج: س\\ط

استورد تنظيم
اطبع(تنظيم.كل_المطابقات(خ"\\d+"، "أ ١٢ ب ٣٤٥"))   # [١٢، ٣٤٥]
```

- تدعم أيضًا النصوص الخام متعددة الأسطر: `خ"""..."""`
- مثالية لأنماط التعبيرات النمطية ومسارات ويندوز والنصوص الحرفية

### الدوال

```text
دالة مساحة_المستطيل(العرض، الارتفاع):
    أعد العرض * الارتفاع

دالة ترحيب(الاسم):
    اطبع("مرحبا", الاسم)

المساحة = مساحة_المستطيل(٥، ٨)
```

الإسناد المتعدد مفيد لتبديل القيم:

```text
أ، ب = ١، ٢
أ، ب = ب، أ      # تبديل
```

#### القيم الافتراضية والمعاملات بالاسم

يمكن إعطاء المعاملات قيمًا افتراضية، واستدعاء الدالة بالأسماء لقراءة أوضح:

```text
دالة فاتورة(الصنف، الكمية = ١، سعر = ١٠):
    أعد الصنف + ": " + نص(الكمية * سعر)

اطبع(فاتورة("قلم"))                  # تستخدم الافتراضيات
اطبع(فاتورة("دفتر"، ٣))               # الكمية موضعيًا
اطبع(فاتورة("حاسبة"، سعر = ١٥٠))     # بالاسم — الترتيب لا يهم
```

#### الدوال السهمية

دالة على سطر واحد بتعبير واحد، تُخزن في متغير وتُمرر كقيمة:

```text
ضاعف = دالة(س) => س * ٢
اطبع(ضاعف(٢١))                    # 42

عمليات = [دالة(س) => س + ١، دالة(س) => س * ١٠]
اطبع(عمليات[١](٥))                # 50

# تُمرر كمعامل إلى دالة أخرى
دالة طبق(قيمة، تحويل):
    أعد تحويل(قيمة)

اطبع(طبق(٥، دالة(س) => س * س))    # 25
```

#### خريطة / مرشّح / اختزل

دوال جاهزة ذات ترتيب أعلى تعالج قائمة كاملة بدالة تحددها أنت:

```text
أعداد = [١، ٢، ٣، ٤]

خريطة(دالة(س) => س * س، أعداد)         # [1، 4، 9، 16]
مرشّح(دالة(س) => س % ٢ == ٠، أعداد)    # [2، 4]
اختزل(دالة(أ، ب) => أ + ب، أعداد)      # 10 — تطوي القائمة لقيمة
اختزل(دالة(أ، ب) => أ + ب، أعداد، ١٠٠) # 110 — مع قيمة بداية

# تتعامل مع النصوص والمدى أيضًا
خريطة(دالة(ح) => كبير(ح)، "أب")        # [أ، ب]
```

#### المعاملات المتغيرة والتفكيك (جديدة في 1.8)

`...الاسم` في تعريف الدالة يجمع الوسائط الزائدة في قائمة:

```text
دالة مجموع(...أرقام):
    م = ٠
    لكل أ في أرقام:
        م += أ
    أعد م

مجموع(١، ٢، ٣)              # 6 — العدد غير محدود
مجموع()                    # 0

# تُخلط بالمعاملات الثابتة والمتغيرة بالاسم والافتراضية
دالة تقرير(عنوان، دقة = ٢، ...قيم):
    أعد عنوان + ": " + نص(قيم)
```

و`...التعبير` عند الاستدعاء تفتّ القائمة (أو النص أو المدى أو المولد) إلى وسائط:

```text
درجات = [٤٢، ٣٧]
أقصى(...درجات)              # يستدعي أقصى(٤٢، ٣٧)

# التفكيك داخل القوائم الحرفية يدمج المحتوى
ممتدة = [١، ...درجات، ٩]      # [1، 42، 37، 9]
```

### القوائم

```text
فواكه = ["تفاح"، "موز"، "برتقال"]

فواكه[٠]          # "تفاح" — الفهرسة تبدأ من صفر
فواكه[-١]         # "برتقال" — من النهاية
فواكه[٠:٢]        # تقطيع: ["تفاح"، "موز"]
طول(فواكه)        # 3

# الطرق الجاهزة
فواكه.أضف("عنب")       # إضافة عنصر
فواكه.أزل("موز")       # حذف قيمة
فواكه.رتب()            # ترتيب
فواكه.اعكس()           # عكس
فواكه.انبثق()          # سحب آخر عنصر
فواكه.عدد_التكرار("تفاح")
فواكه.انسخ()           # نسخة جديدة
```

### القواميس

```text
شخص = {"الاسم": "خالد"، "العمر": ٣٠}

شخص["الاسم"]          # "خالد"
شخص["الوظيفة"] = "مهندس"   # إضافة مفتاح جديد

# الطرق الجاهزة
```

```text
لكل مفتاح، قيمة في شخص.عناصر():

```

### النصوص والسلاسل المنسقة

#### السلاسل المنسقة — ق"..."

البادئة `ق` (قالب) تحوّل النص إلى قالب تُحقن فيه أي قيمة أو تعبير داخل `{أقواس}` — لا حاجة لقص وتجميع:

```text
الاسم = "سلمى"
العمر = ٢٥

ق"مرحبا {الاسم}"                       # مرحبا سلمى
ق"بعد ٥ سنوات: {العمر + ٥}"             # بعد ٥ سنوات: 30
ق"طول الاسم {طول(الاسم)} حرفًا"          # استدعاء دوال
ق"الاسم كبيرًا: {الاسم.كبير()}"           # استدعاء طرق
ق"هل بالغ؟ {العمر >= ١٨}"               # صح

# عناصر القوائم والقواميس مباشرة
درجات = [٩٢، ٨٨، ٩٥]
ق"أعلى درجة: {درجات[٢]}"

طالب = {"الاسم": "خالد"}
ق"أهلًا {طالب["الاسم"]}"                 # اقتباس متشابه داخل الأقواس — مسموح

# ف-نص داخل ف-نص
ق"التقدير: {ق"«{طالب["الاسم"]}»"}"

# أقواس حرفية — ضعها مضاعفة
ق"القاموس يُكتب: {{مفتاح: قيمة}}"
```

- أي تعبير صالح يمكن وضعه داخل `{}`: حساب، مقارنة، استدعاء دالة أو طريقة، فهرسة، حتى ف-نص آخر
- داخل الأقواس يُسمح بعلامات اقتباس من نفس النوع ما دمت داخل أقواس — `ق"{طالب["الاسم"]}"` تعمل
- `{{` و`}}` تعني قوسًا حرفيًا واحدًا

#### النصوص متعددة الأسطر

ثلاث علامات اقتباس لنص يمتد على عدة أسطر — مع الحفاظ على الأسطر والمسافات:

```text
الشعار = """لغة عربي:
  لغة برمجة بالعربية الفصحى
  من القلب إلى العالم"""

الحوار = '''قال المعلم: "من يريد البرمجة؟"'''
# اقتباسات عادية داخل النص بلا هروب
```

#### الطرق النصية

| الطريقة | الوظيفة | مثال |
|---------|---------|------|
| `استبدل(قديم، جديد)` | استبدال الأجزاء | `"سلام".استبدل("س"، "و")` |
| `قسّم(فاصل)` | تقطيع إلى قائمة | `"أ، ب".قسّم("،")` |
| `اجمع(قائمة)` | دمج قائمة نصوص | `"-".اجمع(["أ"، "ب"])` |
| `شريط()` | إزالة المسافات الطرفية | `" نص ".شريط()` |
| `يبدأ_بـ(نص)` / `ينتهي_بـ(نص)` | فحص البداية والنهاية | `"2024".يبدأ_بـ("20")` |
| `كبير()` / `صغير()` | تحويل الحالة | `"abc".كبير()` → `ABC` |
| `أوجد(نص)` (جديدة في 1.4) | موقع أول ظهور أو `-1` | `"مرحبا".أوجد("حب")` → `2` |
| `يحتوي(نص)` (جديدة في 1.4) | هل النص يتضمن الجزء؟ | `"عربية".يحتوي("عرب")` → `صح` |
| `عدد_التكرار(نص)` (جديدة في 1.4) | كم مرة ظهر | `"أبأبأ".عدد_التكرار("أب")` → `2` |
| `اعكس()` (جديدة في 1.4) | النص معكوسًا | `"مرحبا".اعكس()` → `ابحرم` |

### معالجة الأخطاء

```text
جرب:
    النتيجة = ١٠ / ٠
باستثناء:
    اطبع("لا يمكن القسمة على صفر")
اخيرا:
    اطبع("هذا السطر يُنفذ دائمًا")

# رمي خطأ مخصص
لو العمر < ٠:
    ارفع "العمر لا يمكن أن يكون سالبًا"
```

**ربط الخطأ وقراءته (جديد في 1.5)** — اكتب اسمًا بعد `باستثناء` لتصل إلى تفاصيل الخطأ:

```text
جرب:
    النتيجة = ١٠ / ٠
باستثناء هـ:
    اطبع("حدث خطأ: " + هـ)      # هـ = رسالة الخطأ
```

**أخطاء مخصصة بصنف (جديد في 1.5)** — عرّف صنفًا يرث `استثناء` المدمج، وأرفعه كأي كائن:

```text
صنف خطأ_دفع من استثناء:
    دالة تفاصيل():
        أعد ق"سبب الفشل: {هذا.رسالة}"

جرب:
    ارفع خطأ_دفع("الرصيد غير كافٍ")
باستثناء هـ:
    اطبع(هـ.رسالة)                # الرصيد غير كافٍ
    اطبع(هـ.تفاصيل())             # سبب الفشل: الرصيد غير كافٍ
```

**تحقق (جديد في 1.5)** — يرفع خطأ فورًا إذا كان الشرط خطأ، مفيد لضمان صحفية البيانات:

```text
دالة سحب(الرصيد، المبلغ):
    تحقق المبلغ > ٠، "المبلغ يجب أن يكون موجبًا"
    تحقق المبلغ <= الرصيد، "الرصيد غير كافٍ"
    أعد الرصيد - المبلغ
```

### التعبير الثلاثي

شرط مضغوط على سطر واحد يعيد قيمة — مثالي داخل الإسناد والاستدعاءات:

```text
العمر = ٢٠
الحالة = لو العمر >= ١٨: "بالغ" وإلا "طفل"
اطبع(الحالة)                    # بالغ

# يتداخل أيضًا
تصنيف = لو الدرجة >= ٩٠: "ممتاز" وإلا لو الدرجة >= ٧٥: "جيد" وإلا "متوسط"
```

### تعداد

مجموعة ثوابت مسماة — كل عضو بلا قيمة يأخذ رقمًا تلقائيًا يبدأ من ١:

```text
تعداد يوم:
    السبت
    الأحد
    الاثنين

اطبع(يوم.السبت)                 # يوم.السبت
اطبع(يوم.الأحد.القيمة)          # 2
اطبع(يوم.السبت.الاسم)           # السبت

لو اليوم == يوم.السبت:
    اطبع("عطلة نهاية الأسبوع")
```

ويمكن تحديد القيم صراحة، فيواصل الترقيم بعدها:

```text
تعداد أولوية:
    منخفضة
    عالية = ١٠
    حرجة                        # ١١
```

### البرمجة الكائنية

عرّف أصنافك بكلمة `صنف`، وادفع إلى خصائص الكائن عبر `هذا`:

```text
صنف حيوان:
    دالة إنشاء(اسم):
        هذا.اسم = اسم

    دالة صوت():
        أعد "..."

ك = حيوان("أسد")
اطبع(ك.اسم)
اطبع(ك.صوت())
```

**الوراثة** بكلمة `من`، واستدعاء طرق الأب عبر `الأصل`:

```text
صنف قطة من حيوان:
    دالة صوت():
        أعد "مياو"

صنف موظف من شخص:
    دالة إنشاء(اسم، راتب):
        الأصل.إنشاء(هذا، اسم)          # استدعاء منشئ الأب
        هذا.راتب = راتب
```

- المنشئ هو الطريقة المسماة `إنشاء` وتُستدعى تلقائيًا عند إنشاء الكائن
- الطرق والثوابت تُورّث تلقائيًا، ويمكن إعادة تعريفها في الصنف الابن
- ثوابت الصنف تُعرّف مباشرة في جسمه وتُقرأ من الصنف أو الكائن

**الخصائص المحسوبة (جديدة في 1.5)** — قيم تُحسب عند الطلب وتُقرأ بلا أقواس:

```text
صنف مستطيل:
    دالة إنشاء(العرض، الارتفاع):
        هذا.العرض = العرض
        هذا.الارتفاع = الارتفاع

    خاصية المساحة:
        أعد هذا.العرض * هذا.الارتفاع

م = مستطيل(٤، ٥)
اطبع(م.المساحة)                 # 20 — بلا أقواس، وتتحدث مع الحقول
```

**تحميل العوامل (جديد في 1.5)** — اجعل كائناتك تدعم العمليات عبر طرق خاصة:

| الطريقة الخاصة | تُستدعى عند | مثال |
|----------------|--------------|------|
| `اجمع(آخر)` | `كائن + آخر` | أي عملية `+` أو انعكاسها `٥ + كائن` |
| `اطرح(آخر)` | `كائن - آخر` | | 
| `اضرب(معامل)` / `اقسم` / `باقي` / `قوة` | `*` / `/` / `%` / `**` | |
| `يساوي(آخر)` | `==` و `!=` | مقارنة المحتوى بدل الهوية |
| `أصغر_من` / `أكبر_من` / `أصغر_يساوي` / `أكبر_يساوي` | `<` `>` `<=` `>=` | الترتيب المخصص |
| `نص()` | `اطبع(ك)` و `نص(ك)` والنصوص المنسقة | عرض مخصص للكائن |
| `طول()` | `طول(ك)` | طول الكائن |
| `فهرس(م)` / `عيّن_فهرس(م، ق)` | `ك[م]` / `ك[م] = ق` | فهرسة مخصصة |
| `يحتوي(ق)` | `ق في ك` | عضوية مخصصة |
| `سالب()` | `-ك` | النفي الأحادي |

```text
صنف نقطة:
    دالة إنشاء(س، ص):
        هذا.س = س
        هذا.ص = ص
    دالة اجمع(أخرى):
        أعد نقطة(هذا.س + أخرى.س، هذا.ص + أخرى.ص)
    دالة نص():
        أعد ق"({هذا.س}، {هذا.ص})"

اطبع(نقطة(١، ٢) + نقطة(٣، ٤))   # (4، 6)
```

**عالمي / احذف (جديدتان في 1.5)**:

```text
العداد = ٠
دالة زيّن():
    عالمي العداد                # التعيين يذهب للمتغير العام
    العداد += ١

ق = {"أ": ١، "ب": ٢}
احذف ق["أ"]                     # حذف مفتاح (أو عنصر قائمة أو متغير أو خاصية كائن)
```

**المولدات (جديدة في 1.7)** — دوال تنتج قيمًا تباعًا بكلمة `أنتج`:

```text
دالة فيبوناتشي(الحد):
    أ = 0
    ب = 1
    لكل س في مدى(الحد):
        أنتج أ                # تُسلّم القيمة وتتوقف حتى الطلب التالي
        أ، ب = ب، أ + ب

# التكرار المباشر — والقيم تُنتج عند الطلب فقط
لكل قيمة في فيبوناتشي(8):
    اطبع(قيمة)

# استهلاك كامل أو تقدم يدوي
م = فيبوناتشي(10)
اطبع(قائمة(م))               # كل القيم مرة واحدة
اطبع(م.التالي())             # القيمة التالية يدويًا (خطأ عند النهاية)
```

- المولد **كسول**: لا ينفذ شيئًا حتى أول طلب — مثالي للتسلسلات الضخمة أو اللانهائية
- `لكل` يغلق المولد تلقائيًا عند `كسر` أو الخطأ (تنظيف مضمون)
- تعمل مع `خريطة` و`مرشّح` و`اختزل` و`قائمة()` و`اختر` مباشرة
- المولدات تعمل كطرق أصناف أيضًا: `دالة اعد(): أنتج س`

**المزخرفات (جديدة في 1.7)** — وسّع دوالك بعلامة `@` قبل التعريف:

```text
دالة محفوظ(د):
    ذاكرة = {}
    دالة مغلفة(س):
        لو س في ذاكرة:
            أعد ذاكرة[س]
        النتيجة = د(س)
        ذاكرة[س] = النتيجة
        أعد النتيجة
    أعد مغلفة

@محفوظ
دالة فيبوناتشي(ن):
    لو ن <= 1:
        أعد ن
    أعد فيبوناتشي(ن - 1) + فيبوناتشي(ن - 2)
```

- يُطبق المزخرف الأقرب للدالة أولًا، ويمكن تكديس عدة مزخرفات
- المزخرف قد يستقبل وسائط: `@مزخرف(قيمة)`
- يعمل على طرق الأصناف أيضًا — و`هذا` يبقى متاحًا للدالة المغلفة

**الوراثة المتعددة (جديدة في 1.7)** — صنف يرث عدة أصناف بفواصل:

```text
صنف طائر:
    دالة تحرك():
        أعد "يطير"

صنف سباح:
    دالة اسبح():
        أعد "يسبح"

صنف بطريق من طائر، سباح:
    دالة تعريف():
        أعد الأصل.تحرك() + " و" + الأصل.اسبح()   # الأصل = أول صنف
```

- ترتيب حل الطرق **C3** كما في بايثون: الأصل الأول أولًا، والتعارضات المعينية تُحل بلا غموض
- `الأصل.طريقة(...)` تربط الكائن **تلقائيًا** — ويمكن تمرير `هذا` صراحة للتوافق مع الكود الأقدم
- الوراثة الدائرية والترتيبات المتناقضة تُكشف برسائل عربية واضحة

### الواجهات (جديدة في 1.8)

الواجهة **عقد مجرد**: تُعلن الطرق المطلوبة دون تنفيذها، والأصناف المنفذة تلتزم بتوفيرها. أي محاولة لإنشاء كائن من صنف لم ينفذ العقد كاملًا تفشل برسالة عربية واضحة:

```text
واجهة شكل:
    دالة مساحة()          # طريقة مجردة — بلا جسم
    دالة محيط()          # يجب تنفيذها في كل صنف منفذ

    دالة وصف():          # تنفيذ افتراضي — يورثه كل منفذ
        أعد "مساحة: " + نص(هذا.مساحة())

صنف مربع من شكل:
    دالة إنشاء(ض):
        هذا.ض = ض
    دالة مساحة():
        أعد هذا.ض * هذا.ض
    دالة محيط():
        أعد ٤ * هذا.ض

م = مربع(٣)
اطبع(م.وصف())              # يستدعي المساحة المنفذة والوصف الموروث
```

- الطريقة بلا جسم **مجردة**: لا يمكن إنشاء كائن من صنف لم ينفذها — ويُذكر كل ما ناقص
- الطريقة بجسم **تنفيذ افتراضي**: يورثه المنفذون، ويمكن تجاوزه بإعادة تعريفه
- الواجهة نفسها لا تُنشأ منها كائنات — هي عقد لا كود تشغيل
- **وراثة الواجهات**: `واجهة كامل من أساسي:` تضيف التزامات جديدة، ويجب أن ترث الواجهات من واجهات فقط
- **ثوابت الواجهة**: `وحدات = "متر"` تتاح لكل الأصناف المنفذة
- **التزامن مع الأصناف**: `صنف تطبيق من قاعدة، رسم` — صنف عادي + واجهة في نفس الوقت
- الصنف الوسيط قد ينفذ نصف العقد ويبقى مجردًا — ويكمل صنفه الابن الباقي

```text
# طلب POST ببيانات — القاموس يُرسل تلقائيًا بصيغة JSON
```

### وحدة خيوط (جديدة في 1.8)

تنفيذ متوازي بذاكرة مشتركة — شغّل دوال عربية في خيوط مستقلة وانتظر نتائجها:

```text
دالة تحليل(اسم، ثوان):
    وقت.نوم(٠.٠٥ * ثوان)
    أعد اسم + " اكتمل"

خ١ = خيوط.شغّل(تحليل، "أ"، ٢)      # يبدأ فورًا ولا يحجب
خ٢ = خيوط.شغّل(تحليل، "ب"، ٣)
اطبع(خ١.نتيجة())                # تنتظر وتعيد القيمة (أو ترفع خطأ الخيط)
اطبع(خيوط.انتظر_الكل([خ١، خ٢]))   # تنتظر دفعة كاملة وتعيد قائمة النتائج
```

| العضو | الوظيفة |
|-------|---------|
| `خيوط.شغّل(د، وسائط...)` | يشغل الدالة في خيط مستقل ويعيد خيطًا |
| `خيوط.انتظر_الكل(قائمة)` | ينتظر كل الخيوط ويعيد قائمة النتائج |
| `خيوط.قفل()` | قفل حصر لحماية البيانات المشتركة |
| `خيوط.طابور()` | طابور آمن لتمرير الرسائل بين الخيوط |
| `خيوط.معالجات()` | عدد أنوية المعالج |

**طرق الخيط:** `نتيجة()` (تنتظر وتعيد النتيجة وتعيد رفع أخطاء الدالة)، `انتظر()` (تنتظر بلا إعادة)، `حي()` (هل ما زال يعمل؟)

**طرق القفل:** `احجز(مهلة؟)` (يحجز ويعيد صح، أو خطأ عند انتهاء المهلة)، `افرح()` (يفتح)، `محاولة()` (يحجز إن أمكن دون انتظار)

**طرق الطابور:** `أرسل(قيمة)`، `استلم()` (ينتظر رسالة)، `استلم_الآن()` (يرفع خطأ إن كان فارغًا)، `الحجم()`، `فارغ()`

```text
العداد = ٠

دالة زد(مرات):
    عالمي العداد
    تم = ٠
    طالما تم < مرات:
        الحارس.احجز()
        العداد += ١
        الحارس.افرح()
        تم += ١
```

### بروتوكول التكرار المخصص (جديد في 1.10)

أي صنف يعرّف طريقة `تالٍ()` يصبح قابلًا للتكرار بـ`لكل` — عودة `ولا شيء` تنهي التكرار. وإذا عرّف `أول()` فستُستدعى في بداية كل دورة للحصول على مؤشر جديد، فيمكن التكرار على نفس الكائن أكثر من مرة:

```text
صنف عداد:
    دالة إنشاء(من، إلى):
        هذا.الحالي = من
        هذا.النهاية = إلى
    دالة تالٍ():
        لو هذا.الحالي > هذا.النهاية:
            أعد ولا شيء          # إشارة الانتهاء
        القيمة = هذا.الحالي
        هذا.الحالي = هذا.الحالي + 1
        أعد القيمة

لكل س في عداد(١، ٥):
    اطبع(س)                      # ١ ٢ ٣ ٤ ٥

اطبع(٣ في عداد(١، ٥))            # صح — عامل في يمر على العناصر
اطبع([...عداد(١، ٤)])            # نشر العناصر في قائمة
```

| الطريقة | دورها |
|---------|-------|
| `تالٍ()` | تعيد القيمة التالية، وعودة `ولا شيء` تنهي التكرار (مطلوبة) |
| `أول()` | تعيد كائن المؤشر في بداية كل دورة (اختيارية) — الافتراضي الكائن نفسه |

يعمل البروتوكول مع `لكل` (مع `كسر` و`استمر` والتفكيك `لكل أ، ب في`) ومع عامل `في` (إن لم يعرّف الكائن `يحتوي`) ومع النشر `...` في القوائم والاستدعاءات، ويرثه الأصناف الأبناء ويمكنهم إعادة تعريفه.

كلها ترفع خطأ عربيًا واضحًا عند تمرير قائمة فارغة أو غير عددية.

### خادم اللغة LSP (جديد في 1.10)

خادم بروتوكول خادم اللغة الكامل يوفر تجربة تحرير حية لأي محرر يدعم LSP (VS Code وNeovim وغيرهما):

```bash
python3 arabi.py --لغة     # يخدم القنوات القياسية (stdin/stdout)
```

| الميزة | ما يوفره |
|--------|----------|
| تشخيص لحظي | أخطاء الصياغة وتحذيرات الفاحص تظهر أثناء الكتابة |
| إكمال تلقائي | كلمات محجوزة، جاهزات، أعضاء الوحدات والأصناف، أسماء الملف، مقتطفات |
| استدلال الأصناف | بعد `متغير.` يستدل صنف المتغير من إسناده فيعرض طرقه |
| تلميح عند التعليق | تواقيع الدوال مع توثيقها وأعضاء الوحدات |
| رموز المستند | الدوال والأصناف والواجهات والتعدادات وطرقها في شريط التنقل |
| الانتقال إلى التعريف | F12 ينقلك إلى تعريف الدالة أو الطريقة داخل الملف |

الخادم **لا يشغل كود المستخدم أبدًا** — التحليل والفحص فقط، فهو آمن تمامًا.

### فهم القوائم والقواميس (جديد في 1.11)

بناء متتاليات في سطر واحد — أقوى من `خريطة` و`مرشّح` مجتمعتين:

```text
[س * س لكل س في مدى(10)]                    # تحويل: [0، 1، 4، 9، …، 81]
[س لكل س في أعداد إن س % 2 == 0]            # ترشيح بشرط
[س * 1.1 لكل س في المبيعات إن س > 100]      # تحويل وترشيح معًا
[أ + ب لكل أ، ب في نقاط]                    # تفكيك الأزواج
[أ * ب لكل أ في ص لكل ب في ع]               # عبارات لكل متتالية (ضرب ديكارتي)
{ن: طول(ن) لكل ن في أسماء}                  # فهم قاموس — المفتاح المتغير يُحسب كل دورة
{"الحد": س لكل س في القيم}                  # مفتاح ثابت: اقتبسه — وآخر قيمة تغلب
[[صف[ع] لكل صف في مصفوفة] لكل ع في مدى(3)]  # فهم متداخل: نقل مصفوفة
```

القواعد:

| البند | الدلالة |
|-------|---------|
| المتتاليات | قوائم ونصوص ومدى وقواميس (تعطي مفاتيحها) ومولدات وأي صنف يعرّف `تالٍ` |
| الشرط `إن` | اختياري لكل عبارة — يرشّح قبل الوصول للعنصر التالي |
| التفكيك | `لكل أ، ب في أزواج` يفكك كل عنصر على هدفين أو أكثر |
| النطاق | نطاق مستقل: متغيرات العبارات لا تسرّب للخارج ولا تخترق متغيرات بنفس الاسم |
| المفاتيح المجرّدة | في فهم القاموس `{ن: …}` المفتاح متغير — ولتثبيته اقتبسه `"ن"` |

### الكود الوسيط Bytecode (جديد في 1.11)

تحليل المصدر أبطأ مرحلة عند تشغيل البرامج الكبيرة ومشاريع الوحدات المتعددة. عربي الآن يترجم شجرة البرنامج إلى **كود وسيط مخزن** ويحمّله فورًا في التشغيلات التالية:

```text
برنامج.عربي  ← يُحلل مرة واحدة →  __بايت__/برنامج.بيت  ← يُحمّل فورًا بعد ذلك
```

- **تلقائي بلا إعداد**: التشغيل العادي يكتب الذاكرة عند غيابها ويستخدمها عند صلاحيتها — للبرنامج الرئيسي وكل وحدة `.عربي` مستوردة
- **تسريع حقيقي**: القياس على ملف من 2000 سطر — 20 مللي ثانية من الذاكرة مقابل 136 مللي ثانية تحليلًا كاملًا (نحو **٧ أضعاف**)، والفارق يتسع مع كِبَر المشروع
- **إبطال ذكي**: أي تعديل على المصدر (حجمًا أو زمن تعديل) أو تغيّر إصدار اللغة يعيد الترجمة تلقائيًا — لا تحديثات يدوية ولا مخاطر قِدَم
- **أمان الدوران**: ذاكرة تالفة أو ناقصة تُتجاهل بأمان وتُعاد الترجمة من المصدر، والكتابة ذرية عبر ملف مؤقت ثم استبدال

```text
python3 arabi.py برنامج.عربي        # أول تشغيل: ترجمة + تشغيل (تُكتب الذاكرة)
python3 arabi.py برنامج.عربي        # التشغيلات التالية: تحميل فوري من الذاكرة
python3 arabi.py --بايت برنامج.عربي # ترجمة فقط دون تنفيذ (يفيد التوزيع والتحقق)
python3 arabi.py --لا-بايت برنامج.عربي  # تشغيل متجاوزًا الذاكرة تمامًا
python3 arabi.py --لا-دولاب برنامج.عربي # تنفيذ شجري خالص بلا دولاب افتراضي
```

مجلد `__بايت__/` وملفات `.بيت` مُتجاهَلان في `.gitignore` تلقائيًا — مثل `__pycache__` في بايثون، أضِفهما إلى `.gitignore` في مشروعك إن وزّعت الكود.

### سجل الحزم (جديد في 1.12)

نظام إدارة حزم كامل بالعربية: فهرس مركزي، نسخ دلالية، تبعيات تُحل تلقائيًا، ملف قفل، وتثبيت واستيراد بلا أي إعداد:

```text
python3 arabi.py حزمة تثبيت اسم_الحزمة   # تثبيت من السجل مع تبعياته
python3 arabi.py حزمة تثبيت              # تثبيت تبعيات المشروع من بيان حزمة.json
python3 arabi.py حزمة قائمة              # الحزم المثبتة ونسخها وتبعياتها
python3 arabi.py حزمة بحث كلمة           # البحث في الفهرس بالاسم أو الوصف
python3 arabi.py حزمة إزالة اسم          # إزالة (يُمنع إزالة حزمة يعتمد عليها غيرها)
python3 arabi.py حزمة تحديث [اسم]        # التحديث إلى أحدث نسخة في السجل
```

بنية المشروع بعد التثبيت:

```text
مشروعك/
├── حزمة.json            بيان مشروعك (اختياري): الاسم والنسخة والتبعيات
├── قفل.json             قفل التثبيت: النسخ المثبتة بالضبط (مثل package-lock.json)
└── حزم/                 الحزم المثبتة (مثل node_modules)
    └── اسم_الحزمة/
        ├── حزمة.json    بيان الحزمة: الاسم والنسخة والمدخل والتبعيات
        └── الكود.عربي    ملف المدخل (الاسم.عربي افتراضيًا أو حقل المدخل)
```

الاستيراد تلقائي بعد التثبيت — المفسّر يبحث في `حزم/` بعد مجلد البرنامج و`وحدات/` و`مكتبات/`:

```text
استورد ادوات_نص
من احصاء_متقدم استورد تقرير
```

قيود النسخ المتعرفة في التبعيات:

| القيد | المعنى |
|-------|--------|
| `"1.2.3"` | تطابق تام |
| `">=1.0"` / `">1.0"` / `"<=1.0"` / `"<1.0"` | مقارنات معتادة (الناقص يُكمل بصفر) |
| `"^1.2.3"` | متوافق مع الرتبة الكبرى: من 1.2.3 حتى أقل من 2.0.0 (و^0.2.3 حتى أقل من 0.3.0) |
| `"~1.2.3"` | ترقيعات فقط: من 1.2.3 حتى أقل من 1.3.0 |
| `"*"` | أي نسخة |

فهرس السجل ملف JSON بسيط. مصدره الافتراضي مستودع `arabi-registry` على GitHub، ويُستبدل بمتغير البيئة `عربي_الفهرس` أو العلم `--الفهرس` (ويدعم المسارات المحلية فيعمل النظام كاملًا بلا شبكة):

```json
{
  "ادوات_نص": {"النسخة": "1.4.0", "الوصف": "أدوات معالجة النصوص",
               "المصدر": "مجلد ببيان أو ملف .عربي أو .zip أو رابط"},
  "احصاء_متقدم": {"النسخة": "2.1.0", "الوصف": "حسابات إحصائية",
                  "المصدر": "https://example.com/احصاء_متقدم.zip"}
}
```

أمان التثبيت: كل ملف `.عربي` في الحزمة يُفحص نحويًا قبل الكتابة، واسم الحزمة يجب أن يكون معرفًا قابلًا للاستيراد، واسم المصدر في الفهرس يجب أن يطابق بيان الحزمة، والتبعيات الدائرية تُكشف وتُرفض برسالة تُظهر السلسلة.

### الدولاب الافتراضي (جديد في 1.13)

الكود الوسيط في 1.11 سرّع **التحميل** (تجاوز التحليل اللفظي والنحوي)، والدولاب الافتراضي في 1.13 يسرّع **التنفيذ نفسه**: عند أول استدعاء لدالة تُترجم أجسامها إلى تعليمات بايت-كود تنفذها حلقة واحدة سريعة بدل المرور الشجري على العقد (استدعاء طريقة لكل عقدة). الترجمة تُخزن على الدالة نفسها فتُدفع مرة واحدة:

```text
دالة مجموع_حتى(ن):
    مج = 0
    س = 1
    طالما س <= ن:
        مج = مج + س
        س = س + 1
    أعد مج
```

| البرنامج القياسي | الممسح الشجري | الدولاب الافتراضي | التسريع |
|------------------|---------------|--------------------|---------|
| حلقة `طالما` حسابية (٢٠٠ ألف دورة) | 1456 مللي ثانية | 515 مللي ثانية | **2.83×** |
| تعاود فيبوناتشي(٢١) (٥٧ ألف استدعاء) | 325 مللي ثانية | 159 مللي ثانية | **2.04×** |
| فرز فقاعي (٣٠ عنصرًا) | 5.4 مللي ثانية | 3.4 مللي ثانية | **1.58×** |
| استدعاءات طرق أصناف كثيفة (٣٠ ألفًا) | 331 مللي ثانية | 252 مللي ثانية | **1.32×** |

القياس ببايثون 3.12 (أفضل خمس تشغيلات) — والنتائج تتغير بحسب جهازك لكن النسب تبقى في نطاقها.

كيف يضمن الدولاب تطابق الدلالات؟ **بالاحتياط الشفاف** — الترجمة لا تفشل أبدًا لأنها تغلف ما لا تدعمه:

- **الجمل السريعة** تترجم إلى تعليمات صريحة: التعبير، الإسناد (بما فيه الفهرسة والخصائص والمركّب)، `لو/وإلا إذا/وإلا`، `طالما`، `لكل` (القوائم والقواميس والنصوص والمدى)، `أعد/كسر/استمر/تجاهل`.
- **التعبيرات السريعة**: الحرفيات، الأسماء، العمليات (بقيم `و/أو` القصيرة والثلاثي)، الاستدعاءات الموضعية، الفهرسة، الطرق والخصائص، القوائم والقواميس، النصوص المنسقة.
- **كل ما عدا ذلك** (جرب، بدّل، طابق، صنف، استورد، فهم، سهمية، تقطيع، مولدات...) يُغلّف بتعليمة احتياطية تنفذها **المسارات الأصلية نفسها** في المفسّر — فتظهر الأخطاء بنصوصها وأرقام أسطرها المعتادة تمامًا.
- كسر/استمر العابرة من جمل احتياطية (ككسر داخل بدّل داخل حلقة) تُمسك وتوجَّه للحلقة الأعمق كما لو نفذها الممسح.
- ٢٨ تعليمة فقط، والعمليات الحسابية على الأعداد الخالصة لها مسار فوري متطابق مع دلالات `_binop` (القسمة والباقي والأس لها قواعد خاصة فلا تُسرّع أبدًا).

وعلم `--لا-دولاب` يعطّل الترجمة كليًا (ممسح شجري خالص) للمقارنة أو التشخيص:

```bash
python3 arabi.py examples/36_الدولاب_الافتراضي.عربي        # بالدولاب (افتراضي)
python3 arabi.py --لا-دولاب examples/36_الدولاب_الافتراضي.عربي  # بلا دولاب
```

والضمانة العملية: **كل الاختبارات الثمانمئة والسبع والسبعين والأمثلة تنفذ بالوضعين وتُقارن مخرجاتها حرفيًا** في اختبارات التكافؤ — اختلاف حرف واحد يُفشل الاختبار.

### الملف التنفيذي المستقل (جديد في 1.14)

منذ الإصدار 1.14 يوزّع المفسّر **ملفًا تنفيذيًا واحدًا اسمه `عربي`** — يحمل داخله كل شيء: المحلل اللفظي والنحوي، المفسر والدولاب الافتراضي، الوحدات الثماني عشر، مدير الحزم، أدوات `--نسق/--افحص/--وثق`، خادم اللغة، وREPL. يعمل على أي جهاز **بنفس نظام التشغيل بلا بايثون نهائيًا**، ويظهر في `--نسخة` وصف «تنفيذي مستقل»:

```text
$ ./عربي --نسخة
عربي — الإصدار 1.14.0 — تنفيذي مستقل

$ ./عربي -c 'اطبع("مرحبا من تنفيذي بلا بايثون!")'
مرحبا من تنفيذي بلا بايثون!
```

كل الأدوات تعمل عبره كما تعمل عبر المصدر:

```text
./عربي برنامج.عربي          تشغيل برنامج (بالكود الوسيط والدولاب الافتراضي كاملين)
./عربي                      المفسر التفاعلي REPL
./عربي -c "كود"             تنفيذ كود مباشر
./عربي --تحقق ملف.عربي      فحص الصياغة
./عربي حزمة تثبيت اسم       مدير الحزم كاملًا (تثبيت/إزالة/قائمة/بحث/تحديث)
./عربي --لغة                خادم اللغة LSP للمحررات
./عربي --عامل المضيف:منفذ [--مفتاح سر]  عامل موزع يخدم مهام موزع (1.18) ويوقع التحدي بالمفتاح (1.19)
./عربي --نسق/--افحص/--وثق   أدوات النظام البيئي
```

**البناء من المصدر** على أي نظام يملك بايثون:

```bash
python3 -m pip install pyinstaller
scripts/بناء_التنفيذي.sh        # أو: python3 -m PyInstaller عربي.spec --noconfirm --clean
```

الناتج في `dist/عربي` (نحو ١٢ ميغابايت على لينكس). ملف المواصفة `عربي.spec` يستثني الوحدات الرسومية غير المستخدمة لتقليص الحجم، وسكربت البناء يفحص الناتج فورًا (`--نسخة` + كود تجريبي) للتأكد من سلامته. وملاحظتان مهمتان:

- **الثنائي مرتبط بنظام التشغيل ومعماريته**: لبناء نسخة ويندوز أو ماك شغّل السكربت نفسه على ذلك النظام — المصدر نفسه يعمل في كل مكان.
- **ذاكرة الكود الوسيط والعالميات تعمل كما هي**: التنفيذي يكتب `__بايت__/` ويقرأ الحزم من `حزم/` نسبةً إلى مجلد البرنامج المُشغَّل، لا نسبةً إلى موضع التنفيذي.

### غير المتزامن (جديد في 1.15)

الدالة غير المتزامنة تعمل في خيط مستقل **فور استدعائها**، ويعيد الاستدعاء قيمة **مهمة** — فتُطلق عدة أعمال معًا ثم تنتظر ما تشاء:

```text
غير متزامنة دالة جلب_الصفحة(الرابط):
    استجابة = شبكة.اطلب(الرابط)
    أعد استجابة["النص"]

م١ = جلب_الصفحة("https://example.com")   # بدأت فورًا
م٢ = جلب_الصفحة("https://example.org")  # وهذه معها بالتوازي

نصوص = انتظر_الجميع([م١، م٢])            # ينتظر الاثنين ويعيد النتائج بترتيبها
فائز = سباق([م١، م٢])                    # أول من ينتهي (البقية تواصل في الخلفية)
اطبع(انتظر فائز)                          # «انتظر» توقف السطر حتى تنتهي المهمة
```

قواعد النموذج:

- **تعريف**: `غير متزامنة دالة الاسم(...):` — تعمل كدالة عادية في كل شيء: الافتراضيات، المعاملات بالاسم، `...المتغير`، الإغلاق، والطرق داخل الأصناف.
- **الاستدعاء يعيد مهمة ولا ينتظر**: أطلق الأعمال أولًا ثم انتظر ما تشاء، ومتى فشلت مهمة رُفع خطأها بكائنه الأصلي فتمسكه `جرب` كما لو حدث في السطر نفسه.
- **طرق المهمة**: `جاهز()` فحص فوري بلا انتظار، `نتيجة()` ينتظر ويعيد، `الخطأ()` يعيد رسالة الفشل بعد الانتهاء أو `ولا شيء`، و`انتظر()` ينتظر بلا نتيجة.
- **`انتظر_زمن(ثوان)`**: نوم داخل المهمة يوقفها هي وحدها — بقية المهام تجري.
- **كلمة سياقية لا تكسر شيئًا**: `انتظر` تظل اسمًا صالحًا، وطرق مثل `خيط.انتظر()` و`خادم.انتظر()` كما هي، و«انتظر» تعمل على خيوط وحدة `خيوط` أيضًا.

### تنزيل الملفات (جديد في 1.15)

```text
عدد_البايتات = شبكة.تنزيل("https://example.com/صورة.png"، "صورة.png")
```

- تنزيل **ثنائي آمن** يعيد عدد البايتات المكتوبة، مع مهلة اختيارية (١٠ ثوان افتراضيًا)
- أخطاء الشبكة ورموز الحالة وكتابة الملف ترفع رسائل عربية واضحة يمسكها `جرب`
- مع غير المتزامن: **تنزيلات متوازية بسطرين** — `م١ = انزل(رابط١)` و`م٢ = انزل(رابط٢)` ثم `انتظر_الجميع([م١، م٢])`

### تجمع الخيوط (جديد في 1.16)

غير المتزامن يفتح خيطًا لكل مهمة — ممتاز للتوازي، لكن لو قدمت مئات الأعمال دفعة واحدة فتح مئات الخيوط. **التجمع** يحل المشكلة: عدد ثابت من الخيوط العاملة يُعاد استخدامه، فتُقدَّم كل الأعمال وتُنفذ بترتيبها بحد أقصى من التزامن تحدده أنت:

```text
تج = تجمع(٤)                        # أربعة خيوط عاملة تعاد استخدامها
مهام = []
لكل صورة في القائمة:
    مهام.أضف(تج.قدّم(عالج، صورة))    # تُربك لحظة التقديم وتُنفذ عند انفضّ خيط

نتائج = انتظر_الجميع(مهام)           # النتائج بترتيب التقديم كالمعتاد
تج.إنهاء()                           # توقف قبول الجديد وتنتظر تصفية كل المقدَّم
```

قواعد التجمع:

- **`قدّم(دالة، معاملات...)`** تعيد مهمة (`مهمة.نتيجة()` و`جاهز()` و`الخطأ()` كما في غير المتزامن تمامًا) — تقبل الدوال العادية والسهمية و**غير المتزامنة** والطرق المرتبطة بالكائنات وحتى الدوال الجاهزة، مع دعم كلمات المفاتيح: `تج.قدّم(يرحب، "سالم"، لقب = "مهندس")`
- **حد التزامن محفوظ تلقائيًا**: ست مهام على تجمع من خيطين؟ لن تعمل أكثر من مهمتين معًا أبدًا — وقياس ذلك داخل اللغة على المثال 38
- **`إنهاء()`** مزدوجة الأمان: تكمل كل المهام المقدَّمة قبل الخروج، والاستدعاء بعدها يرفع خطأً عربيًا واضحًا — واستدعاؤها من داخل مهمة على التجمع نفسه لا يعلّق
- **`حجم()`** تعيد عدد الخيوط العاملة، و`نوع(تج)` تعيد «تجمع خيوط»
- **تكافؤ كامل مع الدولاب الافتراضي** — التجمع يعمل بالوضعين بنفس الدلالات والأخطاء

### توازي العمليات (جديد في 1.17)

الخيوط تشارك الذاكرة لكنها تخضع لقفل التفسير العالمي (GIL) — عمل حسابي خالص لا يتوازى بينها. **وحدة `عمليات`** تحل المشكلة من جذورها: كل عمل يعمل في **معالج مستقل** بمفسّره الخاص وذاكرته المعزولة، فتُستهلك كل أنوية المعالج فعلًا:

```ruby
من عمليات استورد شغّل، تجمع، معالجات

دالة مجموع_مربعات(ن):
    م = ٠
    لكل س في مدى(ن):
        م = م + س * س
    أعد م

# عمل واحد في عملية منفصلة — انتظار بكلمة 'انتظر' المعروفة:
ع = شغّل(مجموع_مربعات، ٢٠٠٠٠٠)
اطبع(انتظر ع)

# تجمع عمليات يوزع المهام على الأنوية ويعيد النتائج بترتيب التقديم:
تج = تجمع(معالجات())
مهام = []
لكل حجم في [١٠٠٠٠٠، ٢٠٠٠٠٠، ٣٠٠٠٠٠]:
    مهام.أضف(تج.قدّم(مجموع_مربعات، حجم))
اطبع(انتظر_الجميع(مهام))
تج.إنهاء()
```

- **ما الذي يعبر حدود العملية؟** الأعداد والنصوص والقوائم والقواميس، والدوال العربية بجسمها وترويستها وإغلاقها (حتى التعاود عبر الاسم العالمي ونمط المصنع بالإغلاق الذاتي)، والأصناف بوراثتها وثوابتها، والكائنات بحقولها فتعود بطرقها الصالحة، والتعدادات، والأخطاء المخصصة **بهويتها** فتصلك `جرب/باستثناء` بصنفها الصحيح
- **ما الذي لا يعبر؟** الكائنات الحية المرتبطة بخيوط المفسّر (الخيوط والمهام والأقفال والطوابير والمولدات والتواريخ واتصالات قواعد البيانات) — تُرفض برسالة عربية واضحة **لحظة التقديم** لا بعد فوات الأوان، والعملية الابن تبني مفسّرًا كاملًا بوحداته الثماني عشر فتجد الدالة كل الجاهزات
- طرق العملية: `نتيجة()` و`الخطأ()` و`جاهز()` و`انتظر()` و`معرف()` (معرف نظام التشغيل — يقارنه بـ`عمليات.معرفي()` لتتأكد أن العمل انفصل فعلًا)، وطرق مهمة التجمع نفسها بدون `معرف`
- مهلة أمان ١٢٠ ثانية لانتظار النتيجة، والتنفيذ عبر `multiprocessing` بنمط `spawn` موحدًا على لينكس وويندوز وماك — آمن مع خيوط المفسّر ولا يتأثر بنمط النظام

### الحوسبة الموزعة (جديد في 1.18)

المعالجات المنفصلة تجاوزت حدود العملية الواحدة — **وحدة `موزعة`** تتجاوز حدود الجهاز نفسه: موزع مركزي يستقبل اتصالات العمالة من أي جهاز في الشبكة، وكل مهمة تنفذ في العامل البعيد بمفسّر كامل، والنتيجة تعود للنادل مهما نُفذ عملها:

```ruby
من خيوط استورد شغّل
من موزعة استورد موزع، عامل

# على جهاز الموزع:
م = موزع(7700)                     # وبدون منفذ = 7700 افتراضيًا، والصفر اختيار تلقائي

# كل عامل على أي جهاز (خيط هنا — أو على أجهزة أخرى بالأمر الجاهز:
# arabi --عامل عنوان_هذا_الجهاز:7700)
خ = شغّل(عامل، "127.0.0.1"، م.منفذ())
م.انتظر_العمال(1)                  # حجب حتمي حتى تكتمل العمالة

دالة مضروب(ن):
    لو ن <= ١:
        أعد ١
    أعد ن * مضروب(ن - ١)           # التعاود يعمل في العامل البعيد

ت = م.قدّم(مضروب، ٦)               # الدالة تعبر الشبكة بهويتها
اطبع(انتظر ت)                      # 720
م.إنهاء()                          # تصفية الجاري ثم وداع العمالة
```

- **طرق الموزع**: `قدّم(دالة، معاملات…، كلمات)` تعيد مهمة موزعة، `عمال()` عدد المتصلين، `منفذ()` الفعلي بعد الربط، `عنوان()` المرتبط، `حجم()` عدد المقدَّم كله، `انتظر_العمال(عدد؟، مهلة؟)` حجب حتمي، `إنهاء()` يوقف القبول وينتظر التصفية ثم يودّع
- **طرق المهمة الموزعة**: `نتيجة()` و`الخطأ()` و`جاهز()` و`انتظر()` و`معرف()` — الواجهة نفسها، فتعمل مع `انتظر` و`انتظر_الجميع` و`سباق` دون أي فرق
- **لا تضيع مهمة**: انقطاع عامل (أو تعطله) يعيد أعماله الطائرة إلى رأس الطابور فتخدمها عمالة أخرى، والمهام المنتظرة تُصرف فور توفر أي عامل حتى أثناء `إنهاء`
- **ما الذي يعبر الشبكة؟** نفس ما يعبر حدود العملية: القيم البسيطة والدوال بإغلاقاتها والأصناف والكائنات والتعدادات وأخطاء المستخدم بهويتها — والحزمة تُرمّز لحظة التقديم فترفض القيم الحية قبل أن تشغل أي جهاز
- **النقل**: TCP بإطارات موسومة بالطول (٤ بايتات + بيانات) وحد أقصى ٢٥٦ م.ب للإطار، ومهلة أمان ١٢٠ ثانية لانتظار النتيجة
- **المصادقة بالمفتاح (جديد في 1.19)**: مرر مفتاحًا سريًا معاملًا ثالثًا للموزع والعامل معًا — `موزع(0، "0.0.0.0"، مفتاح)` و`عامل(المضيف، المنفذ، مفتاح)` — فيصبح البروتوكول: الموزع يرسل تحديًا عشوائيًا (nonce من ٣٢ بايتًا) والعامل يوقعه HMAC-SHA256 بالمفتاح المشترك، والتحقق بمقارنة زمن ثابت — والعامل المخالف يُرفض برسالة عربية واضحة (مفتاح خاطئ / موزع بلا مفتاح / موزع مفتاحي بلا تحدٍّ) وتظل الشبكة الحرّة تعمل كما في 1.18 تمامًا. المصادقة تمنع العمالة الأجنبية — والبيانات العابرة لا تُشفَّر فتظل القاعدة: شبكة موثوقة أو نفق مشفر

### الأمان والتشفير (جديد في 1.19)

اللغة تحتاج حماية بياناتها كأي نظام إنتاجي — **وحدة `تشفير`** تجلب كل ذلك من مكتبة بايثون القياسية وحدها (بلا أي تبعيات): بصمات تحفظ صحة البيانات، وتوقيع يثبت المصدر والسلامة، ومفاتيح عشوائية لا تُخمَّن، وكلمات مرور لا تُخزَّن أبدًا إلا بصمةً بملح عشوائي، واشتقاق مفاتيح من أسرار بشرية:

```ruby
استورد تشفير

# البصمات — صحة البيانات (ست خوارزميات: sha256 الافتراضي، sha512،
# sha384، sha224، sha1، md5)
بصمة = تشفير.هش("ملف مهم")                   # sha256 ستر عشري
بصمة = تشفير.هش("ملف مهم"، "sha512")          # أو أي خوارزمية أخرى
اطبع(تشفير.هش512("نص"))                       # اختصار sha512

# توقيع الرسائل — المرسل والمستقبل يتشاركان المفتاح السري
مفتاح = تشفير.مفتاح_آمن()                      # 32 بايتًا عشوائيًا (64 حرفًا)
توقيع = تشفير.هوماك("أمر تحويل"، مفتاح)
# عند الاستلام: تحقق بزمن ثابت فلا يتسرب شيء من التوقيت
صالح = تشفير.مقارنة_آمنة(توقيع، تشفير.هوماك("أمر تحويل"، مفتاح))

# العشوائية الآمنة — للأسرار لا للألعاب (عكس عشوائية.عدد)
رمز_جلسة = تشفير.رمز_آمن(32)                   # base64url لروابط وإعادة ضبط
قرعة = تشفير.عدد_آمن(100)                      # 0 <= ن < 100 آمن تشفيريًا
قرعة = تشفير.عدد_آمن(50، 60)                   # 50 <= ن < 60

# كلمات المرور — الملح عشوائي لكل كلمة والبصمة PBKDF2-HMAC-SHA256
سجل = تشفير.شفر_كلمة("كلمة_السر"، 200000)      # جولات أعلى = أبطأ للمهاجم
# خزّن السجل كما هو: {"الخوارزمية"، "الجولات"، "الملح"، "البصمة"}
لو تشفير.تحقق_كلمة(إدخال_المستخدم، سجل):
    اطبع("مرحبا بك")

# اشتقاق المفاتيح — من سر بشري إلى مفتاح قناة بطول محدد
مفتاح_قناة = تشفير.مشتق("سر الفريق"، "قناة-الإنتاج"، 32)
```

| الدالة | الوظيفة |
|--------|---------|
| `هش(نص، خوارزمية؟)` | بصمة ستر عشري بأي خوارزمية مدعومة (الافتراضي sha256) |
| `هش512(نص)` | بصمة sha512 مباشرة |
| `هوماك(نص، مفتاح، خوارزمية؟)` | توقيع HMAC ستر عشري |
| `مقارنة_آمنة(أ، ب)` | مقارنة زمن ثابت — لا تكشف التوقيت شيئًا |
| `مفتاح_آمن(بايتات؟)` | مفتاح عشوائي آمن (32 بايتًا = 64 حرفًا ستر عشري) |
| `رمز_آمن(بايتات؟)` | رمز آمن بترميز base64url للروابط والتوكنات |
| `عدد_آمن(حد؟، أقصى؟)` | عدد عشوائي آمن تشفيريًا في مدى |
| `شفر_كلمة(كلمة، جولات؟)` | سجل تخزين آمن (PBKDF2 + ملح عشوائي، 100000 جولة افتراضيًا) |
| `تحقق_كلمة(كلمة، سجل)` | تحقق من كلمة مقابل سجل — صح/خطأ |
| `مشتق(كلمة، ملح، طول؟، جولات؟)` | اشتقاق مفتاح بطول محدد من سر بشري |

وكل هذا يتكامل مع الشبكة الموزعة (1.18): مرر مفتاحًا سريًا معاملًا ثالثًا لـ`موزع` و`عامل` معًا فيصبح لا عامل يُسجّل إلا بتوقيع تحدٍّ عشوائي بمفتاحه — `موزع(0، "127.0.0.1"، تشفير.مفتاح_آمن())` من جهة و`عامل(المضيف، المنفذ، المفتاح_نفسه)` أو `arabi --عامل م:منفذ --مفتاح سر` من الجهة الأخرى. والموزع الحر يبقى كما هو تمامًا (توافق كامل مع 1.18).

## الدوال الجاهزة

| الدالة | الوظيفة | مثال |
|--------|---------|------|
| `اطبع(...)` | طباعة القيم مفصولة بمسافة | `اطبع("أ"، ٥)` |
| `طول(س)` | طول نص/قائمة/قاموس | `طول([١، ٢])` → `2` |
| `مدى(أ، ب، خطوة)` | توليد تسلسل أعداد | `مدى(٥)` أو `مدى(١٠، ٠، -٢)` |
| `إدخال(رسالة)` | قراءة إدخال المستخدم | `عدد(إدخال("أدخل: "))` |
| `عدد(ق)` | تحويل إلى عدد صحيح | `عدد("٤٢")` → `42` |
| `عشري(ق)` | تحويل إلى عدد عشري | `عشري("٣.٥")` → `3.5` |
| `نص(ق)` | تحويل إلى نص | `نص(٣٠)` → `"30"` |
| `قائمة(ق)` | تحويل إلى قائمة | `قائمة(مدى(٣))` |
| `قاموس()` | قاموس فارغ | `قاموس()` |
| `جمع(قائمة)` | مجموع الأعداد | `جمع([١، ٢، ٣])` → `6` |
| `أكبر(...)` / `أصغر(...)` | أكبر/أصغر قيمة | `أكبر([٤، ٩])` → `9` |
| `مطلق(ع)` | القيمة المطلقة | `مطلق(-٥)` → `5` |
| `تقريب(ع، ن)` | تقريب العدد | `تقريب(٣.٧)` → `4` |
| `عشوائي(أ، ب)` | عدد عشوائي بين عددين | `عشوائي(١، ٦)` |
| `اختر(تسلسل)` | عنصر عشوائي | `اختر(["ورق"، "حجر"])` |
| `خريطة(د، ق)` | تطبيق دالة على كل عنصر | `خريطة(دالة(س) => س * ٢، [١، ٢])` |
| `مرشّح(د، ق)` | العناصر التي حققت الشرط | `مرشّح(دالة(س) => س > ٥، ق)` |
| `اختزل(د، ق، ب؟)` | طي القائمة إلى قيمة واحدة | `اختزل(دالة(أ، ب) => أ + ب، ق)` |
| `انتظر_الجميع([م١، م٢])` | ينتظر كل المهام ويعيد النتائج بترتيبها | `انتظر_الجميع([جلب(أ)، جلب(ب)])` |
| `سباق([م١، م٢])` | يعيد أول مهمة تنتهي (البقية تواصل) | `انتظر سباق([م١، م٢])` |
| `انتظر_زمن(ثوان)` | نوم المهمة الحالية وحدها | `انتظر_زمن(0.5)` |
| `تجمع(عدد)` | تجمع خيوط محدود: `قدّم` / `إنهاء` / `حجم` | `انتظر تجمع(٤).قدّم(دالة، ٥)` |
| `نوع(ق)` | اسم نوع القيمة | `نوع("ن")` → `"نص"` |
| `رتّب(قائمة)` | قائمة مرتبة جديدة | `رتّب([٣، ١])` → `[1، 3]` |

## الاختبارات

المشروع مغطى بـ**999 اختبارًا** يغطي المحلل اللفظي والنحوي والمفسر والسلاسل المنسقة والبرمجة الكائنية والوحدات والدوال السهمية وبدّل/حالة والدوال ذات الترتيب الأعلى وكل ميزات 1.5 و1.6 (التعداد والخصائص وتحميل العوامل والأخطاء المخصصة وإطار الاختبارات والخوادم والأدوات) وكل ميزات 1.7 (المولدات والمزخرفات والوراثة المتعددة وقاعدة وترميز وجداول) وكل ميزات 1.8 (الواجهات والمعاملات المتغيرة والتفكيك ووحدة خيوط) وكل ميزات 1.9 (مطابقة الأنماط والسلاسل الخام ووحدة تواريخ) وكل ميزات 1.10 (بروتوكول التكرار المخصص ووحدة إحصاء وخادم اللغة LSP) وكل ميزات 1.11 (فهم القوائم والقواميس والكود الوسيط بذاكرته وإبطاله) وكل ميزات 1.12 (سجل الحزم: النسخ والقيود والفهرس والتثبيت والإزالة والتحديث والقفل واستيراد الحزم) وكل ميزات 1.13 (الدولاب الافتراضي: تكافؤ تفاضلي شامل مع الممسح الشجري على كل الأمثلة وترجمة الدوال وتخزينها والأعلام) وكل ميزات 1.14 (التنفيذي المستقل: كشف الوضع المجمد وسطر الإصدار واسم البرنامج المتكيف وملف المواصفة وسكربت البناء) وكل ميزات 1.15 (غير المتزامن: التحليل السياقي والدلالات والمجمّعات والأخطاء وتكافؤ الدولاب وتنزيل الشبكة بخادم محلي) وكل ميزات 1.16 (تجمع الخيوط: الدلالات وحد التزامن والإنهاء وتكافؤ الدولاب + التوزيع: بيان pyproject وتوافق الإصدارات وتثبيت pip الفعلي وسير الإصدارات) وكل ميزات 1.17 (توازي العمليات: ترميز القيم وفكها بذاكرته الأصناف والتعدادات والإغلاق الذاتي وأخطاء المستخدم عبر العمليات وعمليات شغّل الحقيقية وتجمع العمليات وسباق على مهام العمليات ورفض القيم الحية وتكافؤ الدولاب) وكل ميزات 1.18 (الحوسبة الموزعة: إطارات البروتوكول وحراسه، إنشاء الموزع وتحققاته، تقديم المهام ورفض غير القابل والمولد والقيم الحية، تكافؤ الدولاب، العمالة الحقيقية عبر TCP والنتائج والمعاملات بالاسم والعالميات والأصناف والكائنات وأخطاء المستخدم بهويتها والمتزامن الملفوف والسباق وإعادة طوابير انقطاع العامل والتصفية عند الإنهاء والعامل من سطر الأوامر) وكل ميزات 1.19 (وحدة التشفير: البصمات بالخوارزميات الست وهوماك والمقارنة الآمنة والمفاتيح والرموز وعدد_آمن بمداه، وسجلات كلمات المرور وتحققها بسجلات فاسدة، والاشتقاق الحتمي، وتوقيع التحدي والتحقق منه، والمصادقة الشبكية بأربعة سيناريوهات ناجحة ورفض رباعي واضح: مفتاح خاطئ، عامل مفتاحي عند موزع حر، عامل حر عند موزع مفتاحي، مفتاح فارغ أو غير نصي، والعامل المفتاحي من سطر الأوامر) ورسائل الأخطاء وجميع الأمثلة:

```bash
python3 -m unittest discover -s tests -v
```

وفحص سريع للصياغة بلا تنفيذ:

```bash
python3 arabi.py --تحقق examples/01_مرحبا_بالعالم.عربي
```

## بنية المشروع

```text
arabi-lang/
├── arabi.py                # نقطة الدخول: CLI + REPL + حزمة + --بايت + --لغة
├── arabi_lang/             # حزمة اللغة
│   ├── tokens.py           # تعريف الرموز
│   ├── lexer.py            # المحلل اللفظي
│   ├── parser.py           # المحلل النحوي (AST)
│   ├── nodes.py            # عقد شجرة الصياغة
│   ├── runtime.py          # القيم والدوال الجاهزة والوحدات القياسية
│   ├── tools.py            # أدوات النظام البيئي: منسق وفاحص وتوثيق وحزم
│   ├── lsp.py              # خادم اللغة: تشخيص وإكمال وتلميح ورموز وتعريف
│   ├── bytecode.py         # الكود الوسيط: تسلسل الشجرة والذاكرة المؤقتة
│   ├── packages.py         # سجل الحزم: الفهرس والنسخ والقيود والتثبيت والقفل
│   ├── processes.py        # توازي العمليات: ترميز القيم والعمال والتجمع (1.17)
│   ├── distributed.py      # الحوسبة الموزعة: البروتوكول والموزع والعامل والمصادقة (1.18، 1.19)
│   ├── crypto.py           # الأمان والتشفير: بصمات وهوماك وكلمات مرور وتوقيع التحدي (1.19)
│   ├── vm.py               # الدولاب الافتراضي: مترجم البايت-كود وحلقة التنفيذ
│   ├── interpreter.py      # المفسر
│   └── errors.py           # نظام الأخطاء العربي
├── examples/               # 41 مثالًا عمليًا + مجلدا وحدات/ وحزم/
├── editor/vscode/          # امتداد VS Code (تلوين + مقتطفات + عميل LSP)
├── tests/                  # 999 اختبارًا
├── scripts/                # سكربتات البناء: بناء_التنفيذي.sh
├── pyproject.toml          # حزمة بايثون القياسية: pip install + الأمر arabi
├── عربي.spec               # مواصفة بناء الملف التنفيذي المستقل (PyInstaller)
└── .github/                # CI (workflows/tests.yml) + سير الإصدارات الجاهز للتفعيل (workflow-templates/release.yml)
```

# امتداد لغة عربي لـ VS Code

دعم تحرير ملفات لغة «عربي» (الامتداد `.عربي`) في محرر VS Code:

- **تلوين بناء الجملة**: كلمات مفتاحية، نصوص، أرقام (شرقية وغربية)، تعليقات، دوال وأصناف.
- **مقتطفات كود (Snippets)**: اكتب `دالة` أو `صنف` أو `لو` أو `تالٍ` ثم اضغط Tab لتوليد قوالب جاهزة.
- **أقواس وإغلاق تلقائي** وطيّ المقاطع المعنونة بتعليقات `# =====`.
- **دعم RTL**: يعمل جيدًا مع لوحات المفاتيح العربية ومحررات ثنائية الاتجاه.
- **خادم اللغة (LSP — جديد في 1.10)**: تشخيص لحظي لأخطاء الصياغة وتحذيرات الفاحص، إكمال ذكي يفهم الوحدات والأصناف ويستدل على صنف المتغيرات، تلميحات توثيق عند التعليق، رموز المستند في شريط التنقل، والانتقال إلى التعريف — انظر القسم أدناه.

## التثبيت

### الطريقة الأولى: من مجلد الامتداد (مستحسن للتطوير المحلي)

1. انسخ مجلد `editor/vscode` كاملًا إلى مجلد امتدادات VS Code:
   - **Linux / macOS**: `~/.vscode/extensions/arabi-lang/`
   - **Windows**: `%USERPROFILE%\.vscode\extensions\arabi-lang\`
2. أعد تشغيل VS Code.
3. افتح أي ملف بامتداد `.عربي` — سيُفعَّل التلوين تلقائيًا.

### الطريقة الثانية: حزمة VSIX

```bash
npm install -g @vscode/vsce
cd editor/vscode
vsce package          # ينتج arabi-lang-1.10.0.vsix
code --install-extension arabi-lang-1.10.0.vsix
```

## المقتطفات المتاحة

| الاختصار | يولّد |
|----------|-------|
| `دالة` | تعريف دالة كامل |
| `صنف` | صنف مع منشئ `إنشاء` |
| `لو` | جملة شرطية |
| `لووإلا` | شرط متعدد الفروع (لو / وإلا إذا / وإلا) |
| `بدّل` | بدّل مع حالة وافتراض |
| `طالما` | حلقة تكرار |
| `لكل` | حلقة على عناصر |
| `جرب` | معالجة أخطاء جرب/باستثناء |
| `استورد` | استيراد وحدة |
| `منستورد` | استيراد أسماء محددة من وحدة |
| `سهمية` | دالة سهمية `دالة(س) => ...` |
| `اطبع` | جملة طباعة |
| `تالٍ` | طريقة بروتوكول التكرار (إشارة الانتهاء: ولا شيء) |
| `أول` | طريقة تعيد مؤشرًا جديدًا لكل دورة |
| `مؤشر` | صنف مؤشر كامل للتكرار على بنية مخصصة |
| `إحصاء` | استيراد دوال وحدة الإحصاء |

## خادم اللغة (LSP)

منذ الإصدار 1.10 يضم الامتداد عميل خادم لغة يربط المفسر بنفسه بالمحرر:

| الميزة | ما تحصل عليه |
|--------|--------------|
| تشخيص لحظي | أخطاء الصياغة (أحمر) وتحذيرات الفاحص (أصفر) أثناء الكتابة |
| إكمال تلقائي | محجوزات وجاهزات وأعضاء الوحدات، وبعد `متغير.` يفهم صنفه من إسناده ويعرض طرقه |
| تلميح (Hover) | توقيع الدالة وتوثيقها عند تعليق المؤشر فوقها |
| رموز المستند | دالة/صنف/تعداد/متغير في شريط التنقل والمخطط |
| تعريف (F12) | الانتقال إلى تعريف الدالة أو الطريقة داخل الملف |

**الإعداد** (إعدادات VS Code):

| الإعداد | الافتراضي | الوصف |
|---------|-----------|-------|
| `arabi.languageServer.enabled` | `true` | تشغيل الخادم |
| `arabi.languageServer.pythonPath` | `python3` | مسار بايثون |
| `arabi.languageServer.serverPath` | (فارغ) | مسار مجلد لغة عربي الذي يحوي `arabi.py` |

الخادم يتطلب حزمة `vscode-languageclient` في بيئة الامتداد (`npm install`)،
وإن لم تتوفر يعمل الامتداد بلا خادم — التلوين والمقتطفات فقط بلا أي أخطاء.
أوامر اللوحة: «عربي: إعادة تشغيل خادم اللغة» و«عربي: تشغيل/إيقاف خادم اللغة».

الخادم لا يشغل كودك أبدًا: التحليل والفحص فقط — آمن 100%.

## هيكل الامتداد

```
editor/vscode/
├── package.json                    تعريف الامتداد والمساهمات (ومزود LSP)
├── extension.js                    عميل خادم اللغة
├── language-configuration.json     سلوك الأقواس والتعليقات والطي
├── syntaxes/arabi.tmLanguage.json  قواعد التلوين النحوي
├── snippets/arabi.json             مقتطفات الكود
└── README.md                       هذا الملف
```
